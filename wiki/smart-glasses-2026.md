# 智能眼镜赛道 2026

2026 年中智能眼镜赛道的现状速写。基于 [[dianwan-keji-ak]] 在 [[smart-glasses-2026-dianwan]] 中的市场观察与作者个人实测。

## 第一梯队：Meta Ray-Ban

- **全球事实标准**，[[dianwan-keji-ak]] 个人 95% 使用时间
- 产品线见 [[meta-ray-ban-glasses]]
- 2026 年关键节点：
  - 5 月：发布 Scriber / Blayzer（近视镜定位）— 详见 [[meta-ray-ban-scriber-blazer]]
  - 5 月：Optics 系列引入 AR1+ 芯片 — 详见 [[ar1-plus-chip]]
  - 9-10 月（预计）：Connect 大会发布 **Hypernova 2** — 详见 [[meta-display-hypernova]]

## 国产追赶者

### 综合产品力
- **理想 Livis**（[[li-xiang-livis-glasses]]）— 综合最强，**录音 + 中文 AI** 差异化
- **夸克智能眼镜** — 显示位置合理但功能不刚需
- 其他若干厂商：[[dianwan-keji-ak]] 签了 NDA 的新品陆续

### 战略观察
- 用 Display 换购国产带显示眼镜 — 国产带显示厂商以"换购"方式回收 Meta Display，对自家产品溢价定价
- "扫码支付 / 智能支付"被作者列为**反对方向**："不要试，对整个行业也不好"

## 关键技术节点

### 显示
- **几何阵列波导**（当前 Hypernova）— 受限于上游肖特玻璃产能与良率，成本压不下来
- **MicroLED**（预期 Hypernova 2）— 更薄更轻更贵

### 芯片
- 高通 AR1 / AR1+ 双轨并行（[[ar1-plus-chip]]）
- 新基线带来 6-12 个月软件适配空窗期

### 镜片
- 依视路 GEN S 第九代变色片（[[photochromic-lens-essilor-gens]]）
- 偏光片用于开车场景

### 形态
- 30g (无镜片) / 50g (含中等度数镜片) 是 2026 现实底线
- 双眼镜轮换是续航最优解（详见 [[smart-glasses-form-factor]]）

## 营销 vs 现实

| 营销话术 | 现实 |
|---------|------|
| "全球最轻 14.9g" | 不含镜片或手板，[[dianwan-keji-ak]] 拆解后驳斥 |
| "一副走天下" | 撑不到一天，必须两副轮换 |
| "智能眼镜反人性" | 重量在进步，AR1+ 比 AR1 省电 |
| "Meta 用户数据被滥用" | [[dianwan-keji-ak]] 立场看淡 |
| "扫码支付黑科技" | 作者明确反对，认为污染行业 |

## 用户分层建议（来自 [[dianwan-keji-ak]]）

1. **日常听歌、打电话、拍照** — Meta Wayfarer，第一梯队
2. **需要全天戴近视镜** — Meta Scriber（推荐）或 Blayzer
3. **拍视频 / 出国 / 海外生活** — Meta Display（Hypernova）
4. **录音 + 中文 AI 是刚需** — 理想 Livis
5. **完美主义** — 两副以上轮换：Meta Optics + Display + 国产录音款

## 长期判断（[[dianwan-keji-ak]] 立场）

- 智能眼镜 = 未来 = "无数科技公司、凯文凯利、研究者已经论证过的方向"
- 用马车 → 汽车的类比反驳"反人性"批评
- 重量肯定向下，但短期内（2 年）单眼镜全天用不可能
- 隐私问题"看淡"，不是核心采购决策因子
