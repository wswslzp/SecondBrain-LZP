## 核心要点速览

1. **三领域对 GPT-6 Astra 的体感温差巨大**：在 **Coding 与通用 Agent** 领域，Astra 只是渐进式长程稳定性与前端审美提升，远不及当年 Claude Opus 4.5 到 4.6 的范式跃迁；但在 **具身机器人** 与 **生物医学（AI for Science）** 领域，Astra 构成了分水岭式的节点——一个发布报告里只字未提机器人的通用基座模型，转身空降机器人评测榜首并让大批 Benchmark 失效，在科研界也促使团队从 Claude 全面切换至 Astra。
2. **个人 Agent 商业化卡在“云端 IP 封锁”与“身份确认”**：Meta Muse（给每人配一台云端电脑、每周送约值 100 美元的 1 亿免费 Token）与 Instinct（估值一个月从 25 亿飙至 100 亿美元）重拾了当年 Manus 的 Browser Use 路线，但迅速撞上同一堵墙——**Amazon 已屏蔽 Meta Muse 的商用云 IP**。商家害怕“1 个用户派 20 个云端 Agent 疯狂比价刷爆流量却只有 1 份消费力”。破局唯有靠**软硬件结合与端侧本地运行**（30B 级私有小模型 + 用户专属硬件/家庭 IP），向商家证明 **1:1 的真实人类身份代表关系**。
3. **前沿实验室真正烧钱的黑洞是 AI for Science**：C 端日常聊天的 Token 消耗并不算夸张，真正吞噬海量算力的是未解科学难题。例如 OpenAI 动用约 **1 万个子 Agent** 攻克数学界的纳维-斯托克斯（Navier-Stokes）方程，发出 270 万条消息、消耗约 **1300 亿输出 Token**，按零售价（Astra 输入 $10/M、输出 $50/M）折算高达 **2200 万美元**。
4. **Computer Use 意外成为生物医学“古董软件”的救星**：生物信息学中大量必用工具（如 MultiQC 等）写于十多年前，UI 简陋、术语晦涩。Astra 因在预训练中吃透了网上的教程（Tutorials）与用户日志（User logs），不仅能直接通过屏幕视觉替科研人员操作这些老旧软件，还能反过来充当“操作教练”，教会跨学科学生使用专业工具。
5. **机器人迎来“GPT 时刻”，控制分层边界被大幅下压**：Astra 首次将大模型的思维链（CoT）反思转化为低层物理动作修正（如撞桌后主动抬高机械臂、捏窄劈叉的花茎再插进花瓶、把手往右伸两厘米），直接打破了传统“VLM 只做高层任务规划、具身小模型做底层控制”的清晰楚河汉界，也让传统的 **TAMP（任务与运动规划）** 在 Agentic 时代重回台前。
6. **Astra 在机器人上的四大硬伤与“快慢系统”合流**：① **极慢**（内部加密长 CoT 高度冗余，简单与复杂任务耗时相近，视频需 16–24 倍速看，无法做抖毛巾、倒水等高动态任务）；② **缺直觉物理**（不懂水会洒、玻璃会碎的瞬间反应）；③ **弱于旋转、插孔与双臂灵巧操作**（如完全叠不了衣服——语言难以描述的任务就做不好）；④ **无法形成肌肉记忆**（第 3 次起耗时永远卡在 45 分钟常数，不能像人一样越练越快）。未来必然走向 **<10B 端侧快决策模型（系统1）+ Astra 级推理与 3D 理解（系统2）** 的结合；许华哲预测 **2028 年初（18 个月后）** 通用机器人将可凭语言指令完成家庭 90% 的日常任务。
7. **机器人数据标注进入“生肉 vs. 熟肉”暗战**：传闻 OpenAI 因嫌外部标注错误且为保密，目前只买未标注的原始数据（“卖生肉/石油”）。真正高附加值的“熟肉数据”必须把每一次抓取成功或失败背后的**物理因果与直觉物理**（位置偏上还是沾水太滑）标清楚，单价可翻 **10 倍以上**。
8. **AI 制药的真瓶颈不在“干实验代码”，而在 30% 完成度的湿实验设计与动物代谢周期**：现有生物医学 Benchmark 已退化为 Kaggle 式的干实验编程题（Astra 在此已超越顶尖人类教授），且大模型因安全审查过度动辄拒答（迫使科研人员改用 Kimi K3 或 Muse Spark 1.3）。但任何新药分子都必须经过**小鼠（数周）→ 猕猴（4–8 个月）→ 授权大药厂（>1000 万美元 License 费）→ 临床人体实验**的物理周期。当前 AI 设计具体湿实验方案的完成度仅约 **30%**，缺乏根据实验室现有器材“看菜做饭”的资源调度能力。
9. **从“Computer Use”走向“Human Use（人类/湿实验调度）”**：王晟提出，未来 AI for Science 的核心范式是 **Instruction Generation（指令生成）**——由 AI 根据科研预算（如 10 万美元）和设备约束，向人类实验技术员（Technician）或实验室机器人下达清晰无歧义的湿实验指令；湿实验外包公司（如刚融资 4000 万美元、与 Anthropic 深度合作的 **Adaptyv Bio**）正通过 **MCP 协议**直连大模型，构建无上限（Uncapped）的湿实验数据飞轮。

## 一、引子：2026 年九月 AI 狂潮与三个行业的同台对表

2026 年 9 月到 10 月初，硅谷 AI 圈经历了一场罕见的高密度震荡。

先是 [[openai|OpenAI]] 正式发布 **[[gpt-6-astra|GPT-6 Astra]]**，总裁 Greg Brockman 在发布会上高调宣布：“AGI 已经到来。”颇具戏剧性的是，这份发布会技术报告里原本只字未提机器人，但 Astra 转身就空降了各大机器人评测基准的榜首，甚至让沿用多年的不少机器人 Benchmark 直接宣告失效。业内有人自嘲道：**机器人领域苦苦等待了这么多年的“GPT 时刻”，没想到最后等来的居然是 GPT 自己。**

几乎在同一时间窗口内，应用层、模型层与科学界的新闻接踵而至：
- **C 端与 B 端 Agent 狂飙**：Astra 发布仅 5 天后，Meta 上线了个人智能体 **Meta Muse**，直接给每位用户配了一台云端虚拟电脑，短短两周便冲上美国 App Store 榜首；其竞争对手 **Instinct** 的估值在一个月内从 25 亿美元暴涨至 **100 亿美元**；xAI 旗下的 **Grok Bot** 也正式开放企业级部署。
- **“系统1”概率模型异军突起**：一家名为 TypeSafe 的公司推出了名为 **Jev** 的新物种——它不写字、不生成长文本推理，专门给不同选项打概率，借用丹尼尔·卡尼曼《思考，快与慢》的概念自封为 **“系统1（快思考）”模型**，发布仅 24 天便狂揽 **8.7 亿美元融资**，估值达 **75 亿美元**。

## 二、Computer Use 的跨界奇效：当生物医学“古董软件”遇上视觉智能体

在节目第一部分，华盛顿大学助理教授王晟分享了一个连 AI 开发者都未曾预料到的现象：**GPT-6 Astra 的 Computer Use（计算机操作）功能，竟然在生物医学科研圈里率先出圈了。**

如果用朱哲清的一句话定义，**Computer Use** 就是让模型通过视觉理解人类看到的屏幕与 UI 界面，直接通过控制鼠标点击和键盘输入，串联几十个动作来完成任务——它与传统 API 调用的根本区别在于：**你不需要向 AI 开放底层接口，也不需要给密码，AI 像一个坐在电脑前的人类一样直接使用软件。**

为什么这项能力会在生物医学界引发轰动？
- **痛点：遍地“难用但必用”的古董级科研软件**。王晟指出，生物医学领域有大量行内默认必用的经典分析软件和网页工具（例如 Astra 发布会上演示的质控汇总工具 **MultiQC**）。这些软件大多编写于十多年前，UI 界面极其简陋反人类，且充斥着晦涩的领域专业术语。对于跨学科背景的学生或研究者来说，光是学会怎么点按钮、怎么配参数，门槛就高得惊人。
- **Astra 的破局：把全网教程与报错日志“吃”进了视觉操作里**。王晟团队实测发现，只需给 Astra 一句简单的自然语言提示词（Prompt），它就能行云流水地操作这些古董软件。王晟推测，Astra 不仅提升了屏幕视觉定位能力，更重要的是**在预训练阶段把互联网上关于这些生物软件的所有教程（Tutorials）、前人留下的用户日志（User logs）和报错反馈全部以文本形式学了进去**——它不仅“看得见按钮”，而且“真懂这个软件的脾气”。
- **意外收获：人类通过看 AI 操作来学软件**。在传统观念里，生物医学界对新 AI 工具的接受度往往偏低；但现在，学生和研究人员通过观察 Astra 是怎么一步步移动鼠标、怎么在古董软件里勾选参数的，反而把它当成了手把手的“软件教学老师”。
- **白昼与黑夜的双模型工作流**：王晟坦言，虽然 Astra 反应偏慢，但在科研场景下，“慢”反而让人安心，意味着它在做更深度的思考。如今他们实验室形成了一套固定的日夜分工：**白天需要快速交互反馈时，用反应快的其他模型；到了晚上临下班前，就用 Astra 设计一条持续 8 到 24 小时的复杂长程科研 Pipeline，让它在实验室电脑上稳稳当当地跑上一整晚。**

## 三、个人 Agent 的商业化死结：Meta Muse 会重蹈 Manus 的覆辙吗？

如果说科研人员在实验室里用 Computer Use 是顺风顺水，那么当科技巨头试图把基于浏览器操作（Browser Use）的个人 Agent 推向数亿普通消费者（ToC）时，迎面撞上的却是一堵由商业利益筑起的高墙。

### 1. 从 API 幻想到退回 Browser Use：重走 Manus 老路

曾几何时，硅谷普遍乐观地认为：未来所有 App 和网站都会主动开放 API，提供原生智能体接口（Agent-native access）。但朱哲清（Bill Zhu）指出，过去一段时间的残酷现实击碎了这个幻想——无论是亚马逊（Amazon）这样的电商巨头，还是 Expedia 这样的在线旅游平台，**大量掌握核心交易闭环的第三方平台根本不愿意向外部 Agent 开放 API。**

于是，为了完成订机票、比价购物、找客服等 C 端高频任务，最近爆火的 **Meta Muse** 和百亿估值独角兽 **Instinct**，不约而同地在后台接上了浏览器（Browser Use），给每个用户分配一台云端虚拟机。

“从背后的虚拟机设置来说，Meta Muse 跟当年的 **Manus** 是非常像的，”朱哲清一针见血地指出，“当年 Manus 最开始也是主打 Browser Use，结果很快就被各大网站全部封杀（Block）掉了。”正因为消费级网页的路被堵死，Manus 后期才不得不与 Genspark 一样掉头转向“白领办公效率”；同理，[[claude-code|Claude Code]]、Claude Cowork 乃至 ChatGPT Work 之所以统统往白领工作流偏移，核心原因正是**消费级生活服务网站一旦发现你是云端跑来的 AI 机器人，就会立刻把你屏蔽。**

事实上，历史的剧本已经在重演：**亚马逊（Amazon）目前已经直接屏蔽了 Meta Muse。**

### 2. 算一笔惊人的烧钱账：每周白送 100 美元 Token + 堪比 GPU 贵的 CPU 沙箱

除了被商家封禁，C 端通用 Agent 还要面对恐怖的单位经济模型（Unit Economics）倒挂：

| 成本维度 | 行业实测数据与对比（朱哲清口述） | 商业后果 |
|---|---|---|
| **免费 Token 补贴** | Meta Muse 给每位用户提供**每周 1 亿免费 Token**；即便全按 Input 成本估算，也相当于**每周每用户补贴约 100 美元** | 靠纯烧钱换取 App Store 榜首，极难像当年完全免费的 Google 搜索或社交网络那样靠低边际成本自然扩张 |
| **前沿模型路由成本** | **GPT-6 Astra 定价为输入 $10/百万 Token、输出 $50/百万 Token**（约为 GPT-6 Sol 的 4–5 倍）。朱哲清实测：在 Claude 20x 订阅用尽后充值 100 美元，仅做 **2–3 轮**复杂 Agent 交互便全部烧光 | 坊间传闻 Meta Muse 虽主用自研 Muse Spark，但遇到难题可能路由（Route）至 OpenAI 模型。若哪怕 **10% 的流量**路由给 Astra 或 Fable，单用户月均成本就可能飙升至 **200 美元**，获客成本彻底失控 |
| **云端虚拟机与 CPU 沙箱** | 浏览器沙箱极耗内存（RAM）与 CPU。Pokee.ai 在做强化学习（RL）大型批量试跑（Rollout）时发现，**云厂商的虚拟 Sandbox 服务贵得离谱，CPU 租金一度与 GPU 持平**，逼得团队只能自己去租大型物理 CPU 服务器自建沙箱 | 每一个云端 Agent 背后都是一台常驻或高频唤醒的虚拟电脑，在当前全球内存与硬件涨价周期下，基础设施账单同样惊人 |

至于 B 端企业市场，朱哲清观察到的现实更是冰火两重天：虽然 xAI 开放了相对主动的 **Grok Bot** 企业部署，但身边人多停留在尝鲜阶段（核心编码与工作流用 Codex 或 [[claude-code|Claude Code]] 即可解决）；而在真正的传统行业（如法律 Legal、医疗 Healthcare），大批员工甚至还在为**“如何脱离 Microsoft Copilot 的泥潭、争取自由使用 Codex 和 Claude Code 的权限”**而苦苦挣扎。走在最前面的人已经用上万个子 Agent 解数学题，走在后面的人却连基础工具都还没用顺。

### 3. 破局之道：为什么“1:1 身份确认”倒逼软硬件结合与端侧小模型？

既然云端虚拟机的商用 IP（哪怕套上 Bright Data 等商业住宅代理 IP）终究会被亚马逊和奢侈品网站拦截，个人 Agent 的出路究竟在哪？

朱哲清与泓君在对话中提炼出了一个极具洞察力的商业逻辑——**问题的本质不是商家反感 AI，而是云端虚拟机无法证明“这个 Agent 背后代表唯一的一个真实人类消费者（Identity）”。**

- **商家的真实恐惧（1 vs. 20 的流量灾难）**：如果一个真实用户原本就要逛亚马逊，现在他派自己的 1 个 Agent 替他逛，转化率和消费能力还是 1:1，商家其实是可以接受的。但如果是云端虚拟机模式，一个用户瞬间派生出 **20 个 Agent**，这 20 个 Agent 的总消费力依然只有 1 个人，却在网站上 24 小时疯狂比价、抓取页面，把商家的流量漏斗、推荐算法和服务器负载搅得天翻地覆——商家自然要封杀你。
- **为什么商家不敢封你家里的电脑？** 因为一旦封了你家庭宽带的本地浏览器，你本人也就上不了亚马逊了。
- **终局：端侧硬件绑定身份 + 30B 本地私有模型**。朱哲清判断，这波 ToC Agent 最终一定会落地到**软硬件结合（Wearables / AI PC / AI Box）**。如果 Meta 能把智能眼镜等可穿戴硬件铺开（见 [[meta-ray-ban-glasses]]），或者让 Agent 直接跑在用户的个人终端（如 Mac mini、AI PC）上，硬件本身就能成为**物理级的人类身份锚点（Identity）**——商家确认“这台设备就代表这一个活生生的人”，就会愿意把 Access 权限打开。
- 这也正是朱哲清创立 **Pokee.ai** 主攻 **30B 左右小模型**的战略支点：通过与高通（[[qualcomm|Qualcomm]]）、Intel、AMD、联想、惠普等硬件厂商合作，把 30B 模型装进本地 AI PC 或私有算力盒子里。如果个人日常 **60%–70% 的广度 Token** 都能在本地私有算力上免费生成、浏览器沙箱直接在本地运行，既绕开了云端 IP 封锁与数据隐私焦虑，又把高昂的云端 Frontier Model 调用压缩到只处理最难的 30% 任务，整个商业闭环才能真正跑通（见 [[sovereign-ai]]、[[memory-wall]]）。

## 四、机器人的“GPT 时刻”：Astra 如何用长思维链重构具身智能？

如果说 Agent 领域的创业者还在为商业模式算账，那么机器人领域的学者在过去三周里经历的，则是一场实打实的认知地震。

### 1. 劈叉的花茎与金门大桥：当思维链（CoT）变成物理动作

在 GPT-6 Astra 发布前，历代大模型（无论是 Claude Opus 4.5、4.6 还是 Fable）在机器人评测上几乎毫无建树——“原来不能做的，升级后依然不能做，定性上没有任何变化。”但许华哲坦言，Astra 带来的冲击是**定性级**的：在 **RoboDojo** 等公认的机器人仿真基准上，Astra 直接屠榜拿下了第一名，甚至让许多传统 Benchmark 失去了区分度。

为什么一个没有专门针对机器人发报告的通用大模型，会突然打通任督二脉？许华哲从清华与破壳机器人的密集实测中，拆解了 Astra 的三大惊艳之处：

1. **极强的跨本体适应与反思闭环（CoT-to-Action）**：给 Astra 接入一个陌生的机械臂本体，它能迅速察觉“这台机器人的运动速度偏快”或“工作空间受限”。比如机械臂不小心撞到了桌子，Astra 会在内部思考：“这个桌子还蛮高的，我下一步是不是应该把手抬高一点？”——**它第一次把大语言模型的思维链（CoT）反思能力，直接转化成了物理空间里的动作调整。** 网上传播极广的“机械臂画金门大桥”Demo 正是如此：第一遍画得很拙劣，但它看完画作后自我反思哪里画歪了，迭代几轮后竟画得惟妙惟肖。
2. **三维空间尺寸理解：以“劈叉插花”为例**：许华哲团队做了一个升级版的经典插花实验——故意把花茎底部劈开成两半，形成分叉，导致直接往花瓶口塞会卡住。令人震惊的是，Astra 观察到分叉后，自主推理出：**“因为花茎分叉变宽了，我应该先用夹爪捏住分叉处，把它捏窄一点，再往花瓶里塞。”** 这种基于 3D 几何尺寸的临场应变，在非动态物理操作中展现了极高的泛化水平。
3. **几张图生成仿真世界（Real-to-Sim）**：过去把真实实验室迁移到仿真环境（Real-to-Sim），需要拍摄海量多角度照片视频，再由工程师手工标定修改；现在只需给 Astra 几张照片和一句指令，它就能在极短时间内复现出整个办公室或实验室的 3D 仿真环境。

### 2. 控制层边界下压与 TAMP（任务与运动规划）的复活

长期以来，具身智能界普遍认同“大脑 + 小脑”的分层架构（见 [[humanoid-robot-hardware]]），但**“分层的这一刀究竟切在哪”**一直是争论焦点：
- **旧共识**：上层 VLM（视觉语言模型）只负责粗粒度的任务规划（比如你说“做西红柿炒蛋”，VLM 输出“1. 打开冰箱门；2. 拿出西红柿；3. 打鸡蛋”）；至于“手怎么伸过去抓冰箱把手”，全靠底下的具身小模型去执行。
- **Astra 的新冲击（边界下压）**：Astra 直接把上层大模型的控制边界往下压了一大截——它现在下达的指令变成了**“把手往右伸 2 厘米”“把手放在冰箱门把手上，如果没抓住，再往前靠一靠”**。底层执行器几乎退化成了一个只需听懂“往左/往右”的提线木偶。
- **TAMP 重回舞台中央**：这一变化意外激活了机器人学里一个略显古典的分支——**TAMP（Task and Motion Planning，任务与运动规划）**。过去 TAMP 用传统符号规划一步步检查前置条件（“拧瓶盖前必须先确认瓶盖是关着的”），显得死板过时；如今有了 Astra 这样强大的基座模型，通过 Agentic Harness 把规划与底层动作控制重新编织在一起，反而焕发出了全新的生命力。

### 3. 惊艳背后的四大短板：为什么几万亿参数的基模当不了机器人的唯一大脑？

在最初两周的震惊与恐慌过后，随着测试走向深水区，许华哲和同行们也摸清了 Astra 的真实能力边界。面对“未来上层 VLM 会不会无限下压、彻底取代具身小模型实现端到端控制”的激进观点，许华哲给出了明确的否定回答，并列出了 Astra 的四大硬伤：

| 短板维度 | 实测表现与具体案例（许华哲口述） | 底层技术原因 |
|---|---|---|
| **1. 速度极慢（内耗型长 CoT）** | 网上所有 Astra 控制机器人的视频**必须用 16 倍速或 24 倍速播放**，原速下几乎是在漫长等待；像“抖毛巾”“倒水”这类高动态、时间敏感任务完全无法直接控制（倒水卡顿一下水就溢出来了） | 模型参数量巨大，且内部加密的真实 CoT 极长；更重要的是**面对简单任务和复杂任务时，它的思考时长几乎一样**，在简单动作上产生了严重的内耗冗余 |
| **2. 缺乏“直觉物理”** | 人类随手碰倒装水的杯子会本能反应“水要洒”、碰到玻璃知道“会碎”；Astra 若经过冗长的语言推理也能懂，但在动作执行瞬间毫无物理直觉 | 它的理解仍停留在三维几何尺寸（3D），缺乏底层世界模型（World Model）与毫秒级反射式的物理直觉 |
| **3. 旋转、插孔与双臂灵巧度差** | 抓取桌面物体做空间旋转并塞进墙上小孔需要反复笨拙尝试；在破壳机器人经典的**“用筷子夹小球”**任务中，自研小模型是连续高频试探调整，而 Astra 每夹一次失败都要停下来做长篇归因分析，一旦归因算错就直接卡死僵局；**双臂协同任务（如叠衣服）更是完全做不了** | **“凡是人类语言不太好描述的任务，Astra 的能力都不强。”** 柔体形变、双臂力觉配合与连续高频微调难以用离散语言 Token 精确编码 |
| **4. 无法形成“肌肉记忆”（45 分钟常数陷阱）** | 让 Astra 重复做同一件事：第 1 次花 1 小时，第 2 次优化到 45 分钟，但**从第 3 次开始永远都是 45 分钟，变成了一个常数**！而人类或专用小模型在充分练习后，耗时能从几十分钟缩短到随手几秒钟 | 缺乏把慢思考（System 2）内化、蒸馏为快反射（System 1）的持续参数更新机制，每次都在重新跑推理 |

### 4. 机器人产业洗牌：本体受益、快慢系统与“10 倍差价”的数据标注暗战

基于上述实测，许华哲对具身智能产业链的未来走向做出了四点关键判断：

1. **Real-to-Sim 只是视觉 Hype，Sim-to-Real 瓶颈未解**：很多人欢呼 Astra 让仿真路线复活了，但许华哲指出，Astra 只是把 3D 视觉外观渲染得又快又好，**并没有让仿真器的底层物理引擎变得更准确**（摩擦力、接触形变依然失真，参见 [[physical-ai-computing]]）。因此单靠仿真依然训不出最好的实机策略。
2. **直接利好硬件本体，大脑公司加速分化**：Astra 出炉仅两三周，斯坦福一个课题组就把它接入一台**宇树（Unitree）机器人**，只用两周便做出了家庭任务论文 Demo。这意味着只要硬件本体质量过硬，接上 Astra 就能立刻跑通演示。而做“机器人大脑”的公司将分化为两派：技术弱的会放弃自研大模型，转型做调用 Astra 的**场景部署集成商**；技术强的则会吸收 Astra 的思维链与标注范式，全力攻关**端侧 <10B 参数的快决策专用模型**（若放云端 API，仅限准静态任务、容忍 200 毫秒以上网络延迟）。至于近期爆火的 **Jev** 快系统，实测在摞方块等机器人任务上表现很差——因为它不支持直接输入图像，必须外挂视觉模型转成状态，且缺乏“第一块歪了、第二块往反方向放来平衡”的空间修正能力（不过传闻 OpenAI 即将发布支持图像多模态输入的快系统）。
3. **数据标注分裂为“卖生肉”与“卖熟肉”**：许华哲透露了一个行业传言——**OpenAI 目前在外面只采购完全未标注的原始数据（Raw data）**，一方面是觉得外部公司标得全都不对，另一方面是为了严防自家的标注格式（即模型训练品味）泄露。这让机器人数据公司裂变为两类：
   - **卖生肉（卖石油/原材料）**：纯靠规模苦力，管理上千乃至上万人去采集家庭场景数据；
   - **卖熟肉（高附加值认知标注）**：传统的机器人标注只写一句正向描述（“把杯子拿起来”）；而受 Astra 启发的下一代标注，必须把**因果链条与直觉物理**标清楚——**“这次为什么没抓住？是因为抓的位置偏上了，还是因为物体表面沾了水太滑？”** 谁能通过交易中的局部观察逆向推理出 OpenAI 或 $\pi$（Physical Intelligence）的研究品味，提供这种“熟肉数据”，**单价可以直接翻 10 倍甚至更高**。
4. **2028 年初的激进预测：从“5 个博士驻厂睡 3 个月”到零样本进家庭**：许华哲直言，今天许多所谓的工业具身部署（比如去工厂闭环拧螺丝、上货），背后其实是“派 5 个博士水平的工程师去工厂里睡 3 个月，把稳定性、速度、定制末端夹爪全调好”，这在某种程度上是逆时代的。真正的通用机器人追求的是**零样本泛化部署（Zero-shot Generalization）**——哪怕有一些动作冗余，只要随便派 5 个懂基本体力的普通工人就能快速部署起来（对比 [[robot-workflow-loop]] 中 DYNA 的视角）。他给出了一个令全场惊讶的乐观时间表：**到 2028 年初（距今约 18 个月），通用机器人将开始真正走进家庭，普通人用语言指令就能让它完成家里 90% 的日常家务。**

## 五、AI 制药的真瓶颈：当代码题拿了高分，谁来替大模型养猴子和调配试剂？

当话题转向被视为“前沿实验室最大 Token 吞金兽”的 **AI for Science 与生物医药**时，华盛顿大学助理教授王晟却泼了一盆冷静的冷水。

### 1. 尴尬的真相：生物知识没涨，安全拒答先把科学家逼向了国产与开源模型

“大家以为 Astra 的生物医学能力变强，是因为它懂了更多生物医学知识；但实际上，在专门测 Biomedical Knowledge 的基准上，Astra 并没有提升。”王晟揭开了第一个反直觉的事实：**Astra 在生物医学上的进步，几乎完全来自通用 Coding（编程）、查文献以及跑长程任务能力的提升。**

更让一线科研人员头疼的是**越来越严苛的安全护栏（Safety Guardrails）**：
- 随着 Astra、Claude Opus、Fable 等前沿模型能力增强，它们对涉及生物、病毒、分子合成的任务防范得草木皆兵，动辄触发 **Refuse to answer（拒绝回答）**。
- “大模型的实际使用体验，随着能力的增强其实是越来越差的，”王晟苦笑道。为了推进日常研究，他们实验室内部如今反而大量使用限制较少的 **Kimi K3** 或 **Muse Spark 1.3**；如果非要用 Astra 不可，研究人员必须绞尽脑汁写一套特殊的话术跟模型周旋——*“我绝对不是在做一个危险的生物任务，我只是在设计一个计算机 Benchmark……”*

### 2. Benchmark 的 Kaggle 化与“30% 完成度”的湿实验鸿沟

朱哲清与王晟在对话中达成了一个深刻共识：**目前小模型之所以能在许多 AI for Science 基准上迅速缩小与万亿参数大模型的差距，是因为现有的生物医学 Benchmark 本身就定义错了。**

- **干实验（Dry Lab）已近乎解决**：为了让 AI 好做题，现有的生物 Benchmark 往往给定一个干净的生物数据集，要求预测一个明确的指标（如蛋白质活性分类）。这本质上退化成了一场 **Kaggle 数据科学比赛** 或 **MLE-bench（机器学习工程基准）**。在这类纯计算机模拟的“干实验”代码题上（例如新出的 **Terminal-Bench Science**），王晟亲自下场测试，发现哪怕 Astra 只拿了 60 多分（满分 100），**它写代码解题的表现也已经超过了王晟自己这位顶尖人类教授。**（干实验的下一个纯计算瓶颈，在于如何高效处理单人高达 **2TB** 的海量复杂多组学医疗数据。）
- **真正重要的问题没有标准答案，只能靠湿实验（Wet Lab）验证**：王晟指出一个根本悖论——如果“开发一款治愈某种癌症的新药”已经有了标准答案可以写进测试集，那人类根本不需要去研究它。当 GPT 给你一个抗癌分子式、Claude 给你另一个分子式时，没有任何计算机能裁判谁对谁错，唯一的考场是在真实的房间里，用试管、培养皿、小鼠和猴子做**湿实验**（对比 [[agent-comfort-zone]]）。
- **实验方案设计完成度仅有 30%**：生成分子式只是万里长征第一步（网上有海量分子结构数据可供训练）；真正卡脖子的是**“怎么把这个分子合成出来？在什么温度和湿度下储存？以什么剂量和周期给小鼠注射？”** 在设计具体可执行的湿实验方案上，目前最强的大模型完成度**只有约 30%**，剩下 70% 必须依赖在实验室摸爬滚打多年的资深实验技术员（Technician）大刀阔斧地修改——甚至连普通大学教授都未必比一线技术员更懂这些实操细节。
- **不会“看菜做饭”的 AI**：每个真实实验室拥有的仪器、试剂和设备都不同。王晟打了个生动的比方：**“我这间饭店厨房里只有番茄、鸡蛋和土豆，我让 Astra 设计一道菜，它根本不理解我的库存限制，张口就让我做一桌海鲜大餐。”** 缺乏对真实物理世界资源的感知、协调与调度能力，正是当前大模型在科学发现上的最大盲区。

### 3. 一只猴子四个月：为什么 AI 几小时算出的分子，还是逃不过自然规律？

为什么 AI 在数学领域能一日千里（甚至攻克千禧年大奖难题级别的猜想），在制药领域却迟迟没有诞生一款真正由 AI 独立走完全程并获批上市的新药？

王晟用一条硬核的**临床前研发时间线**给出了答案：

```
[AI 干实验设计分子] ──► [细胞与小鼠实验] ──► [灵长类（猕猴）实验 × 1~2 轮] ──► [License 授权给大药厂] ──► [人类临床 I/II/III 期]
    几小时 ~ 几天            几周时间              4 个月 / 轮（两轮即 8 个月）       授权费通常 > $1000 万         漫长的 5 ~ 10 年
                       （期间 GPT 已迭代一代！）   （AI 制药初创通常止步于此）      （利用大药厂的病人网络）
```

- **自然新陈代谢的硬约束**：当年 **AlphaFold 1 & 2** 刚横空出世、解决蛋白质结构预测时，硅谷曾涌现出一大批 AI Drug Discovery（AI 药物发现）初创公司，但最后绝大多数都折戟沉沙。原因很简单：即便 AI 把前端设计分子的时间从半年压缩到了几小时，药打进小鼠体内，你依然要等几周看它的新陈代谢反应；等小鼠做完，模型都已经从 GPT-6 升级到 GPT-6.1、6.2 了；接着还要在猴子（灵长类动物）身上做 1 到 2 轮实验，每轮至少 **4 个月**。一家典型的 AI 制药初创公司把细胞、小鼠和猴子实验全部跑通，至少需要 **6 到 12 个月**，随后以 **1000 万美元以上**的授权费（License fee）卖给拥有庞大患者网络的大型跨国药企去推进人体临床。
- **AlphaFold 3 开源后的数据护城河：一条动物实验数据值几十万美元**：随着 AlphaFold 3 及社区 OpenFold 等底层工具全面开源，算法本身的壁垒被拉平（如同机器人界的 Pi 开源），竞争彻底转向**私有湿实验数据**。王晟指出，在互联网公开语料里，绝对找不到“某个具体新分子在活体小鼠身上究竟能不能杀死癌细胞”的数据——**在完整动物身上跑通这样一条真实的湿实验数据，价值高达几万乃至几十万美元**（相比之下，买一道奥数题或 Terminal-Bench 编程题只需几千美元）。
- **哪些细分赛道最先跑出来？周期决定一切**：正如 Claude 用 21 小时发现类 CRISPR 的 **ART 新酶系统**、以及 Anthropic 举办蛋白质与酶设计大赛所昭示的，**AI 突破的速度严格正比于该领域湿实验反馈的快慢。** **酶（Enzyme）**作为工业与生活催化剂（例如将地沟油转化为可用油、让洗衣粉在不同水温下保持高活性），实验验证极快且无需漫长的人体临床，商业化落地最快；**蛋白质**次之；而像**人类抗衰老（Longevity）**或**罕见病**这类实验周期极长、数据极度匮乏的领域，大模型依然束手无策。

### 4. 未来图景：从“MCP 云端湿实验”到“AI Prompt 真实世界（Human Use）”

既然算力无法跳过生物代谢，科学家们正在如何重构实验室？王晟描绘了三个正在发生的未来趋势：

1. **前沿 AI 实验室纷纷自建湿实验室，湿实验外包通过 MCP 直连大模型**：
   - [[anthropic|Anthropic]] 不仅吸纳了与 Demis Hassabis 共同获得诺贝尔奖的 AlphaFold 核心缔造者 **John Jumper（江珀）**，还在内部大力招募湿实验团队；同时，Anthropic 与刚融资 **4000 万美元**的初创公司 **Adaptyv Bio** 展开深度合作——AI 模型生成蛋白质设计方案后，直接通过 **MCP（Model Context Protocol）** 协议把指令发给 Adaptyv Bio，后者立即在实验室里启动湿实验验证，省去了中间所有人类沟通成本。
   - 王晟判断，**“湿实验即服务（Wet Lab via MCP/API）”** 将成为极佳的创业赛道；同时实验室本身也必须针对 AI 进行物理改造（Redesign）——先把细胞和前置条件全部备妥，只留出等待 AI 预测的那几步，预测一出立刻加样，把干湿闭环压缩到极致。
2. **构建“无上限（Uncapped）Benchmark”的数据飞轮**：未来的生物评测不应再做“某基因是否致癌”的静态分类题，而应设计没有天花板的连续优化题——比如现有 SOTA 药物能杀灭 30% 的癌细胞，让 AI 持续迭代分子并结合湿实验把杀伤率推向 40%、50%，在追逐无上限目标的过程中源源不断地沉淀高价值湿实验数据。
3. **从 Computer Use 走向 “Human Use（人类调度）” 与 AI 原生仪器**：
   - 过去几年，人类一直在研究怎么写好 Prompt 去指挥 AI；王晟认为，未来的范式将彻底反转，进入 **Instruction Generation（指令生成）——由 AI 来 Prompt 真实世界。**
   - 未来科学家给 AI 的输入不再是“帮我设计一个抗癌药”，而是：**“给你 10 万美元预算，这是我实验室现有的设备清单（做一次小鼠实验 2000 美元、耗时 X 周），请你规划一套完整的实验方案。”** AI 会生成极其清晰、毫无歧义的执行指令，去调度实验室里的机器人或人类技术员（即 **Human Use**）。
   - 更进一步，未来的科学仪器甚至不再需要迎合人类的感官——比如现在的 X 光机、CT 机之所以要把底层物理信号合成为二维/三维图像，只是为了让人类医生的肉眼能看懂；**未来的实验与医疗设备将直接把底层的原始波形和物理信号喂给 AI，彻底跳过“生成人类可读图像”这一步**（与 [[haozhe-wang|王浩哲]] 在 [[atomic-microscopy|ATOMIC]] 中的理念遥相呼应）。

## 六、尾声：当大模型连普通人都不屑“蒸馏”了，人类的价值还剩什么？

节目的最后，主持人泓君抛出了一个令许多人感到寒意的话题：近期不少前沿模型实验室的研究员私下直言，随着训练信号全面转向顶尖专家数据与可验证环境，**“现在很多普通人，甚至连被大模型拿来蒸馏（Distill）的价值都没有了。”**

面对这个略显残酷的判断，三位站在不同维度的研究者给出了截然不同却彼此互补的回答（见 [[distillation]]、[[tasks-vs-jobs]]）：

- **许华哲（机器人视角）：在物理生活世界里，每个普通人都是值得被蒸馏的专家**。
  “在机器人领域绝没有这么悲哀，”许华哲笑道，“因为每个普通人都是生活的专家——你擅长做家常菜，我擅长叠衣服，他擅长走路和跳舞。”今天的具身机器人连普通人的日常动作都远未学会；也许再过一两年，才会演进到“非得找米其林大厨 Gordon Ramsay 或顶尖舞蹈家来蒸馏”的阶段。至少在今天，每一个普通人随手做的一盘西红柿炒蛋，对机器人来说都是求之不得的黄金数据。
- **王晟（科学探索视角）：人类不仅在“反向蒸馏 AI”，更垄断了“定义问题”与“机长背书”的权力**。
  首先，科研中正在发生剧烈的**反向蒸馏（互相蒸馏）**——面对跨学科盲区，王晟自己每天都在高频向 AI 学习新知识，用 AI 激发科研灵感；其次，在明确定义的问题上 AI 已超越顶尖科学家，但**“提出新问题”**（比如人类突然想挑战活到 200 岁、500 岁，或者每个个体独特的身体病痛诉求）永远源于人类自身；最后，生物医药关乎人命与数千万美元的真金白银投入，就像哪怕自动驾驶飞机再成熟、乘客也希望驾驶舱里坐着一位人类机长，哪怕 AI 能出诊断书、病人也希望真人医生亲眼看一眼报告一样，**人类科学家作为最终责任背书者（Accountability）的角色不可替代**（见 [[accountability]]）。
- **朱哲清（模型学习本质视角）：大模型只是“过拟合”了考题，还没有学会人类“从零快速学习”的底层直觉**。
  朱哲清从强化学习与模型训练的底层机制指出，今天看似无所不能的大模型，本质上依然是靠庞大参数死记硬背（Memorize）了海量知识，并在固定 Benchmark 和落地场景上做了高强度的 **Overfitting（过拟合）**。如果脱离逐个场景的过拟合，让一个欠拟合（Underfit）的基础模型像人类一样**从零开始在线交互学习**——比如用 1 个月的真实环境交互达到人类基础医生水平，用 3 个月交互达到大学教授水平——今天的 AI 离这种通用自学习能力还差得太远（见 [[agi-roadmap-ladder]]、[[specialized-intelligence]]）。因此，未来真正值得从人类身上蒸馏的，绝不是某一项表层技能，而是**人类如何用极少样本从零学会新事物的底层思维方式与直觉（Intuition）**。

在节目的收尾，泓君回忆起前不久在《硅谷101》Alignment 2026 年度大会上向王晟提过的一个问题：*“当 Claude 宣布用 21 小时找到类 CRISPR 的新酶系统 ART 时，AI 圈和生物圈的反应有什么不同？”*

王晟当时的回答令她印象深刻：**AI 圈欣喜若狂，觉得 AI 终于开始自主做科学发现了；而生物圈却相当平淡——大家只说了一句：“等在实验室里验证出来了再说吧。”**

“为什么会出现这两种截然不同的反应？”泓君总结道，“因为**模型层的进展和一个行业真正的改变之间，隔着的不仅仅只是智能，还有验证。** 机器人要在真实的物理世界里反复试错，新药要耐心地等老鼠和猴子走完新陈代谢，而个人 Agent 也要去过商家风控和用户身份的那道关。**AI 圈子看到的是陡峭的能力曲线，而行业里的人看到的，是扎扎实实的落地周期。**”
