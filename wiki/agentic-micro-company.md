# Agentic Micro Company (AMC)

[[brett-goldstein]] 描述的新型公司形态：极小团队 + 大量 AI agent。

## 结构

| 组件 | 说明 |
|---|---|
| Tiny Teams | 通才型"球员教练"，每人都是创始人角色 |
| Tons of Agents | 执行绝大多数工作 |
| Custom Software | 自动化和监控业务 |
| [[company-brain]] | agent 的上下文来源 + 软件的后端 |

## 实际案例

- **Block (Jack Dorsey)**: 裁员 40%，重组为小团队 + agent 模式
- 多个创业公司：从零到千万美元营收，数月内，极小团队
- 参考 Sequoia Roelof Botha 的 *From Hierarchy to Intelligence*

## 与 Naval 框架的联系

AMC 是 [[leverage]] 理论的极致实现：
- 代码杠杆 + AI agent 杠杆 → 极小团队撬动巨大产出
- 每个人都是 founder → 对应 [[accountability]]
