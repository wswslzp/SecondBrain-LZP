# 立党 lidang

**立党 lidang** 是一位观点鲜明（opinionated）的中文 AI 评论者/内容创作者，长期在 YouTube、推特发布 AI agent 学习与研究路线。风格直接、爱下判断、常以"我早就说过"的口吻布道自己的方法论。

## 核心主张

- **早期提出 coding/SWE agent 概念**：自称 **2023 年 4 月**就提出 coding agent / SWE agent 概念，**早于姚顺宇 2023 年 9 月**的 ReAct / SWE agent，声称在这个问题上"比所有人都早"。
- **"go-driven"（目标驱动 / 可验证驱动）理念的推广者**：主张 agent 最理想的场景是**封闭、可仿真、可精确验证**的环境——可验证性是 go-driven 的前提。详见 [[agent-comfort-zone]]。
- **手写最小 agent 是大学生第一课**：见 [[build-your-own-agent]]。
- **非程序员应该用 headless 通用 agent，而非手搓 bespoke agent**：见 [[headless-agent-pattern]]。
- **对 multi-agent 有明确取舍**：反对组织架构模拟式 multi-agent，支持 map-reduce 式并行与 go-driven multi-agent。见 [[multi-agent-patterns]]。

## 开源工作

- 在 GitHub 开源了一个 **multi-agent、go-driven** 项目（自称 **1000+ star**），主打"full self coding"与有流程控制的 multi-agent 管理。

## 观点风格

- 爱做**性价比判断**：普通人不必为 95 分模型多花钱，85/90 分够用（[[build-your-own-agent]] 选模型小节）。
- 爱划**能力边界**：AI agent 不是神/超人/黑箱，不能违反 causality / information theory。
- 常用"价值 10 万刀 / 30 万刀"、"每一条都值 1000 万美元"之类的价值标签给方法论定价。
