# Satya Nadella

[[microsoft|Microsoft]] 第三任 CEO（2014 至今），在 [[frontier-systems|Stanford CS153]] 收官一讲中，把「AI 的商业与社会意义」讲成了一套关于 **future of the firm** 的完整世界观（见 [[frontier-ecosystem]]）。他自述是 development economist 之子，长期痴迷「AI 对 Global South 的意义」与 convergence growth。

## Prepared mind：$1B OpenAI 下注（2019）的来处

Nadella 把这笔被视为「点燃 Cambrian explosion」的下注归因于一颗 **prepared mind**：

- **Microsoft 数十年对 natural language 的执念**。2017-18 时他们更相信「symbolic logic + machine learning」，并非深度学习能做出 NLP 突破的 truest believer——但「that was something we wanted to have happen」，于是对**任何有雄心的 natural language 角度**（无论 lineage、无论内外）都「take a shot」，买公司、投项目一大批，OpenAI 只是其中之一。
- **Gates-Grove 生态 DNA**：PC 革命靠 Intel + Microsoft 的 Gates-Grove model；SQL Server 靠与 SAP 的分工（Microsoft 做 database、SAP 做 ERP）。「在 Microsoft 长大，你学会靠 building + partnering 创造企业价值。」所以内部没有「我们自己能做」的 uprising。
- **真正的大决定是 compute concentration**：「it's more than capital... the biggest decision was about compute concentration on a particular effort.」把稀缺算力集中押注，而非单纯出钱。[[scaling-laws|Scaling laws]] 论文让这一押注显得合理。

## 世界观：electricity → light

- 借用前一位讲者的比喻——「as electricity came about, we didn't sell electricity, we sold light」。他承认业界「太沉迷于为技术而 hype 技术」，但世界最终按「我们为一个个社区创造了什么价值」来评判。healthcare 成本曲线、家人真实获得的照护，才是「light」。
- **就业**：任何 disruptive technology 都有真实 displacement，但「humans are the one species that are most adaptive」；当**当前的 intelligence 被 commoditize**，人类会在这一新 commodity 之上创造新价值、获得新 agency 与 wages。见 [[tasks-vs-jobs]]、[[intelligence-as-utility]]。
- **social permission**：若生态变成「a few firms have all the returns，其余都 in bad shape」，「you will absolutely lose social permission」。因此把生态做成 [[frontier-ecosystem|positive-sum]] 是道义也是生存必需。

## Growth mindset：confront your own fixed mindset

- 他强调 growth mindset **不是 instill 而是 invoke**——唤起人人 innate 的东西，且靠 practice。作为领导者，他能做的最重要示范是「**confront my fixed mindset**」。
- 名言式 quip：「everybody likes change, except they want the other person to change, not themselves.」——这正是 growth mindset 之难。
- 三个思想来源（多来自妻子的阅读）：**nonviolent communication**（培养 empathy、不总是触发 amygdala）、**Carol Dweck** 的 growth mindset 研究、以及 **Herbert Simon 的 bounded rationality**（人常「不见自身利益、被 hijack」）。落点金句：「**think of it as your training run** that you need.」

## 给学生的建议：cognitive coverage

- 类比 test coverage 提出 **cognitive coverage**：可以用 10 个、100 个 coding agent 帮你学，但「it's not that I've offloaded to the 100」——关键是**我在 instruct 什么**、以及事后**能否理解它们做了什么**，否则学不到东西。「像同时上 100 门课。」
- 工具演化：开发者工具从「100 个 CLI」走向「管理 CLI 复杂度的东西」——**GitHub app 成了管理 agent sessions 的「new inbox」**。他每天就是这样看「10 个、100 个 agent 在做什么」。
- **generated UI 是新的人-agent 交互面**：GitHub 里新加的 **Canvas** 不是给 agent 用的，而是给人用的——线性的 chat/CLI session 太密、难 scroll，于是用 **Kanban board** 让人和 agent 同屏协作。「generated UI 会是所有产品线里最酷的事之一。」
- 若回到本科，他甚至可能重回 **hardware**（他本是 electrical engineer 后 drift 进 software）——optical networking、system design 都是「unbelievable time」。

## Microsoft 文化

50 年老公司的 core DNA 始终是「developer tools platform + knowledge worker tools company」，但**每逢新平台就重新诠释**这一使命。他 90 年代入职时的 existential competition 是 Novell，如今是「五年前都没听过的某个 foundation lab」——正是这种「对手总是新鲜的」让公司保持 vibrant。见 [[microsoft]]。
