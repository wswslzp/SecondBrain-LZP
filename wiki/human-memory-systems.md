# Human Memory Systems

认知科学中人类记忆的完整分类体系。

## 多重存储模型 (Atkinson & Shiffrin, 1968)

最经典的记忆模型，将记忆分为三个阶段：

1. **感觉记忆** (Sensory Memory) — 毫秒到秒级，自动衰减
   - 图像记忆 (Iconic) ~0.5s | 回声记忆 (Echoic) ~3-4s | 触觉记忆 (Haptic) ~2s
2. **短时/工作记忆** (Working Memory) — 秒到分钟级，容量 7±2 项
3. **长时记忆** (Long-Term Memory) — 理论上无限容量和持续时间

## 长时记忆分类

```
长时记忆 (LTM)
├── 外显/陈述性 (Explicit/Declarative) —「知道什么」
│   ├── 语义记忆 (Semantic) — 世界知识、概念、事实
│   └── 情景记忆 (Episodic) — 个人经历的时空情境
└── 内隐/非陈述性 (Implicit/Non-Declarative) —「知道怎么做」
    ├── 程序记忆 (Procedural) — 运动技能、操作步骤
    ├── 启动效应 (Priming) — 先前刺激影响后续反应
    ├── 经典条件反射 (Classical Conditioning)
    └── 非联合学习 (Habituation/Sensitization)
```

## 特殊记忆类型

- **前瞻记忆** (Prospective) — 记住未来要做的事
- **闪光灯记忆** (Flashbulb) — 重大事件的鲜活记忆
- **自传体记忆** (Autobiographical) — 构建身份认同的生命叙事
- **元记忆** (Metamemory) — 对自己记忆能力的监控
