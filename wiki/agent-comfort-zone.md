# AI Agent 的舒适区：封闭可验证环境

[[lidang]] 认为 AI agent 目前**最理想、最完美**的应用场景有四个共同特征——这也是 "go-driven"（目标驱动）能成立的前提：

1. **封闭环境** —— 本地电脑，尤其是 sandbox 隔离的沙箱，尽量少与外界杂音接触；
2. **可完整编译 / 运行 / 模拟 / 仿真**；
3. **可无限试错**，搜索空间巨大；
4. **可精确验证**。

> go-driven 的前提是你必须**可以验证、可以仿真、可以在本地运行**。只有这样 agent 才能反复迭代、逼近目标。

## 五大舒适区领域

### 1. 编程

本地 run / test / 报错 / 输出结果 / 反复迭代更新。或相对稳定的云环境（AWS 上固定节点）——同样是封闭环境。这是最典型的舒适区。

### 2. 数学（via Lean 4）

用 **Lean 4** 构建证明、本地编译、本地检查（可读 arXiv / 他人 paper 作参考）。这也是一个闭包环境。**难度比编程高得多**，但不代表不可能——会随模型迭代提升。（作者举例：数学公司 Axiom 已融资 1 亿美元。）

### 3. 电子 / 芯片设计

各种 **HDL**（Verilog / VHDL / SystemVerilog / SpinalHDL 等硬件描述语言）、**EDA** 工具、**RTL**、**synthesis**、**仿真**、**verification**——本地设计、本地综合、本地仿真、本地验证。过去 **30–40 年**已有非常成熟完整的本地工具链（买任意 EDA 工具即可）。

> ⚠️ **仿真 ≠ 流片**。仿真不是目的，仿真之后一定要流片、现场测试，才知道芯片到底对不对。

也包括 PCB 设计、系统级仿真、嵌入式单片机仿真。

### 4. MATLAB + Simulink

MATLAB 有 **100–200 个 toolbox**，覆盖机械、热力学、流体、量子、信号、传感器、电力电子、模拟器等仿真。只要买了注册号、有运行环境，就能在本地做完整的真实仿真。

> **每个 toolbox × agent = 一个可自动化研究的新领域。** MATLAB 是"留给人类最好的礼物"、一个大宝库。很多计算机学生不用 MATLAB——这是错的。

### 5. CAD / 机械设计

- **AutoCAD**（用 AI 引擎写 **Lisp** 来操作 AutoCAD）；
- **G-code / 数控机床**；
- **PLC**、大型工业控制系统。

CAD 是完整的设计 + 模拟仿真环境，机械设计这一环可以完全在里面完成。

## 能力边界：agent 不是神

> AI agent 不是神、不是超人、不是黑箱、不是玉皇大帝——**不能违反 causality（因果论）或 information theory（信息论）**。

做不到的事（因为**人**也做不到）：

- 预测明天彩票中什么奖；
- 预测明天微软涨 5% 还是跌 10%、今年最赚 / 最亏的股票；
- 证明黎曼猜想（Riemann hypothesis）、哥德巴赫猜想；
- 预测三年后墨西哥的 GDP、巴黎有没有某家制造业公司。

你若拿 agent 当算命，它一定会给你一个答案（"墨西哥经济一路长虹"），但那只是搜了三五个网页汇总，**不负责任**。

### 判断准则

> 判断一个 agent 能不能解决某任务，**先问：人有没有合理的流程与方法论能系统地解决（哪怕费时）？**

agent 只是在**两个前提**满足时把"人可解的过程"自动化：
1. 有足够多的 context / 数据 / 文档 / 图表 / 数据库；
2. 有足够科学正确的流程与方法论，让 agent 完全参照执行。

没有 context、没有正确流程，agent 也解决不了。

## 反例：金融 / 市场不是舒适区

金融 / 市场是**开放对抗环境**：有对手、几十万人在交易、七八成是量化——无法本地测试、充满杂音与不确定性，**不是舒适区**。

这与 [[ai-quant-system]] 形成对照：那里 [[zostaff]] 用 6 Agent + 3 道硬门（[[three-gate-evaluator]]、Deflated Sharpe）拼命对抗过拟合与市场对抗性——**正因为金融不在舒适区，量化才如此难**。物理世界、信号、电子、流体力学、热力学、气象、地球物理、天体这些"真实且本地可模拟"的领域反而是舒适区。
