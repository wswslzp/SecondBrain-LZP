# 克制作为战略（Restraint as Strategy）

**[[liang-wenfeng|梁文锋]]** 在 [[liang-wenfeng-investor-meeting|投资者交流会]]反复强调的核心命题：**「克制是一种战略。」** 不是道德姿态，而是在 AI 这个「太大、不可独占」的博弈里**赢得长期**的最优解——「你越克制，你越有可能能够做成。」

## 博弈论内核：拿得多的会被拿得少的打败

这是全篇最锋利的一段推理（呼应 [[game-theory]]）：

> 「如果我的目标是占 AI、全人类 GDP 的 5%，理论上算账成立——你看 OpenAI 好像能算得过来。但他会被一个**只要 1%** 的人打败；这时又出来一个**只要 0.1%** 的，又把前面的打败。」

- **拿得多 → 树敌多、阻力大 → 做不成**；「愿景如果是拿得多的，你就会**先输了**」。
- 但也有下界：**拿太少活不下去**（商业逻辑不成立）→ 最终在某处平衡。
- 结论：不追求利润最大化的定价，**只赚一个合理收益**。

## 合理利润 = 十个月回本 ≈ 6 倍

- API 定价逻辑：买一批设备**十个月收回成本**（财务上按 3–5 年摊销，商业上 10 个月够了）≈ **6 倍利润**。
- **不是利润最大化**：在这个价位需求**无弹性**（价格翻倍、token 消耗量区别不大），本可定更高；但他们反而**降价到 1/4**，公司群里「欢呼」。
- 「十个月回本我们能做到，阿里腾讯的成本要比这高好几倍」——**成本能力本身就是护城河**（见 [[china-us-compute-gap]]）。
- 未来合理利润可能降到 4 倍、3 倍——AI 效率太高，暴利「不符合客观规律」，行业必然**收敛**。

## 克制的多重表现

| 领域 | 克制的做法 |
|---|---|
| **开源** | 连最强模型也开源；开源是「克制的一部分」，也是「让利」。见 [[open-weights-strategy]] |
| **C 端** | 去年春节爆火**没去抢用户/变现**——「后面还有西瓜，前面都是芝麻」 |
| **不做超级 App** | 「我们可以做下一个字节/腾讯，但没有这么做」 |
| **不做上游整合** | 不自研芯片（「运营发电厂不必造发电机」）、不做垂直行业闭环 |
| **聚焦** | 只做 AGI 主线，要做的事少→**不用加班**、很从容 |

## 为什么克制反而做得成

- **增加做成 AGI 的概率**：优先级不是「多拿一点份额」，而是「增加我能做成的概率」。
- **凝聚力与人才**：让利让员工「很有成就感」、公司有凝聚力；AGI 这个大愿景「能凝聚更多优秀的人」——**组织上的优势 = 一种降维打击**。
- **没有因善意少拿**：「我并没有因为开源、因为善意而少拿任何东西，反而可能还有加分。这看起来违反直觉，但确实是这样。」

## 与 vault 的关联与对位

- **[[intelligence-as-utility]]**（[[sam-altman]]）：Sam 的「民主化分叉」（~80% 概率把智能作为公用事业推出去）与梁的「克制」殊途同归，但梁把它推到极致——**自愿把可得利益压到最低以求活得最久**。梁甚至用它直接反推 OpenAI「想垄断世界」必然遇挫。
- **[[open-weights-strategy]]**：开源在此从「战术」升级为「克制战略的必然要求」——AI 市场太大不可独占。
- **[[venture-capital-systems]]** / [[ben-horowitz]]：与「AI 时代需求近乎无上限、Wall Street 买 narrative」形成有趣张力——梁认为**愿景拿得多者先输**。
- **[[restraint-as-strategy]] ↔ [[agi-roadmap-ladder]]**：克制让他选「最轻松的技术路线」（先持续学习再具身），二者一脉相承。

## 另一种克制：盲注没那么大

⚠️ 张力：[[liang-wenfeng-investor-meeting|梁文锋]] 的克制来自「拿得多的会被拿得少的打败」，是为了活得更久而压低可得利益。[[ricky-mao|Ricky Mao]] 的克制来自牌桌：通胀是人生的大小盲，但多数人把盲注估得太大，所以大多数牌应该弃，筹码只堆在最好的机会上。一个是少拿以续命，一个是少打以保正期望。并列保留，不合并成同一条战略。
