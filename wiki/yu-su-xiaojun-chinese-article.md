# 苏煜：Agent 不是新词——从逻辑智能体到 Language Agent，以及 OpenClaw Moment

> 整理说明：本文根据张小珺商业访谈录第 139 期《和苏煜聊 Agent 技术史、OpenClaw Moment、边界的消弭和社会的辐射》（YouTube 上传日期 2026-05-01 UTC，时长 2 小时 17 分 49 秒）的音频机器转写整理，按主题重组，不是逐字稿。文字稿来源是本地 ASR，不是平台字幕。文中数字、融资额、论文时间和公司动作均为嘉宾口述，未经独立核实。ASR 专名已按公开资料校正：苏玉 → 苏煜（Yu Su）；Neo Cognition / Neocognition → NeoCognition；OpenCloud / Open Cloud → OpenClaw；ChairGPT / XGPT / Chagipiti → ChatGPT；ALMO → AllenNLP/ELMo 一带的早期语言模型（口述含混，不把具体论文名写死）；Two Former / tool formal → Toolformer；CACT / SeaAct → SeeAct；U-Ground → UGround；Web Arena、OSWorld、SWE-bench、MMMU、Mind2Web、LLM-Planner 按通行写法。仍可疑、正文不采信的听写包括：Lovable 的前身被听成 “AI engineer”、某非参数学习工作被听成 “meta-hotness / out-hotness”、豆包手机被听成 “豆宝手机”。中美舆论对比、裁员与失业是嘉宾个人观察，不代表整理者立场。

## 核心要点速览

1. **Agent 不是 2025 年的新物种。** 苏煜把它定义成三件事：有边界的实体、处在环境里、做有目的的活动。按这个定义，动物和人都是 agent，AI 从 1940 年代起就在追这个目标。
2. **用两个轴看所有 agent：记忆（memory）和自主（autonomy）。** 记忆包括语义知识、情景记忆和程序性记忆；自主包括感知、推理、决策和行动。早期系统两边都很窄。
3. **Language Agent 的定义性特征是把语言当脚手架。** 语言同时撑起理解、弹性推理（chain-of-thought 把计算量和任务难度绑在一起）和行动（自然语言、形式语言、代码）。他不认为 “coding agent” 是另一个物种：编程语言本来就是语言。
4. **终点是 universal digital agent，浏览器 / 桌面 / 手机、GUI / CLI / API 都只是手段。** 边界会消弭，但 GUI 不会消失——人还需要它，长尾软件也不会为了 agent 重写一遍。
5. **OpenClaw Moment 像 ChatGPT Moment：底层能力早已就绪，变的是交互形态和权限姿态。** 他把这看成高度自动化的 personal agent 范式被公众看见的时刻，而不是新算法。
6. **通用智能变便宜之后，差别来自专门化。** NeoCognition 要研究的不是某一个垂直 agent，而是一套能在任意领域里持续学会 “小世界模型” 的方法。
7. **可靠性、速度、成本、安全里的一大部分，在他看来是同一件事：没学会这个世界。** 实习生会犯老师傅不会犯的错。
8. **他担心的不是近期奇点，而是岗位置换快过新岗位和再分配。** 他认为研究者的责任是把专家级 agent 的门槛降到个人能用自己的洞察变现。

## 一、什么叫 Agent：三个条件，两条能力

小珺把这期放在 “AI 从 Chat 走向 Agent” 之后，想要的是一条技术史，不是产品盘点。苏煜先把定义收窄，因为这个词人人都有自己的版本。

对他来说，agent 必须同时满足三点：它是一个有边界的实体，不是一团没有边界的能力；它在某种环境里工作；它不是随机游荡，而是做有目的的活动（goal-directed activities）。动物符合这个定义，人是目前最强的那种。

他接着给了一套可以套到所有 agent 上的框架。

| 能力 | 包含什么 | 早期系统缺什么 |
| --- | --- | --- |
| 记忆 memory | 知识怎么表示、获取、更新、遗忘；语义知识、情景记忆、程序性记忆（例如怎么骑自行车） | 只有有限的逻辑陈述，表达力被逻辑语言绑死 |
| 自主 autonomy | 感知、推理、决策、行动 | 只能接一个问题、跑推理引擎、吐一个答案 |

这两条是一体两面：记忆是自主的基础。人把学到的东西都存在突触里，所以 “所有学到的东西都是 memory”。后面整期对 logical agent、游戏 agent、语言模型和 OpenClaw 的评价，都是在问：记忆有多宽，自主有多活。

## 二、1960–1990：逻辑智能体，以及为什么它带来了 AI 冬天

1950 到 1990 年代的主旋律是 logical agent。典型形态是专家系统：选定一种逻辑语言（一阶谓词逻辑是代表），工程师去采访领域专家，把知识写成逻辑陈述，再配一个推理引擎。新问题来了，就在已有知识上做推演。

这是早期真正能工作的人造 agent，也直接贡献了 1980–1990 年代那次 AI 冬天。专家系统兑现不了自己的承诺。表达力是硬限制：现实世界里绝大部分东西写不进简单逻辑。高阶逻辑、模糊逻辑、概率逻辑只补上很小一块。更大的瓶颈是知识获取：采访、翻译成逻辑、再维护，痛苦、低效、效果有限。

他推荐 Stuart Russell 和 Peter Norvig 的 *Artificial Intelligence: A Modern Approach*（第一版约 1995 年）作为这一阶段的总结。Russell 曾对他说，这本书表面上是 AI 教科书，本质上是一本关于 agent 的书，第一章就在讲什么是 intelligent agent。只是后来这个词被忘掉了。领域随后分化成视觉、自然语言、推理等子领域——“分久必合”是后话。

他的判断很硬：在当时的技术条件下，直接追求一个完备 agent 是 counterproductive。目标太大，对领域发展有反效果。

## 三、2000 年代：神经智能体把一件事做深，语义解析想把入口做宽

2000 年之后，他看到两条平行的努力。

**Neural agent** 的高光在深度强化学习：Atari、AlphaGo、Dota、星际。用记忆/自主来拆，仍然很窄。主体往往是一个很小的网络，几千万参数，顶多到一亿量级——当年很大，今天极小。输入是游戏画面，输出是那一个游戏的动作。记忆里只存这个游戏的规则和感知。自主更简单：看一帧（也许加一点历史），做一次前向传播，执行，环境变了再重复。几乎没有显式推理。不管局面多复杂，计算量都是同一次 forward pass。人不是这样：难的局面会多想一会儿。

通用性只提高了一点点：同一套网络能玩一个系列里的很多游戏，同一套方法能迁移到另一类游戏。它还远不是 “扔进任何环境、用很少样本就学会”。样本效率当时很差，一个简单游戏可能要打几百万局。游戏被当成训练场，既有 Demis Hassabis 的个人偏好，也因为虚拟环境可重复、数据无限、输入输出简单，刚好配得上当时的技术。

**Semantic parsing（语义解析）** 走另一边：把人说的话变成机器能读的形式表示（formal meaning representation）。背后可以是知识图谱、数据库或网站。它扩大的是通信和行动空间——命令一旦能被机器读懂，就能驱动动作。苏煜的博士工作主要在这里。他点名的后来者包括 Percy Liang、Luke Zettlemoyer（RoBERTa，以及更早的 AllenNLP / ELMo 一线；GPT 在很大程度上受这些工作启发），更年轻一代里有港大的 Tao Yu，以及 OSU 的 Huan Sun。这些人后来都出现在语言模型和 agent 的关键工作里。他不把这当成巧合：把语言变成可执行表示，和后来的 language agent 是同一类问题。

两条线的分工可以压成一句：神经 agent 学的是在窄环境里把一件事做深；语义解析学的是把输入输出做宽。到 2020 年，两边都还没汇合。

## 四、Language Agent：语言是脚手架，不是装饰

ChatGPT（2022 年 11 月）之后，景观变了。苏煜把新一代叫做 language agent，并在 2024 年和 Diyi Yang、姚顺宇、Tao Yu 做了一个 tutorial 来定义它。定义性特征不是 “用了大模型”，而是 **语言成了脚手架（scaffold）**：

- **感知**：人和 agent 可以用灵活的语言交互，不再被固定的游戏动作空间卡住。
- **推理**：chain-of-thought 让计算量跟着任务走。难的任务多生成一些 token，每个 token 都是一次前向传播，于是有了自适应计算。早期神经 agent 做不到这一点。
- **行动**：自然语言加上形式语言、机器语言，在数字世界里几乎是全能媒介。
- **记忆**：预训练是一次以语言为材料的压缩，把表层形式压成对世界的一个表示。他承认早年 “随机鹦鹉”（stochastic parrot）的批评有市场，但认为现在更站得住的图景是：训练在建世界模型，而这个表示直接驱动感知、推理和行动。

他用生物史做类比，明确说这是类比，不是证据。地球生命花了极长时间才到真核生物、哺乳动物；人属和智人在进化史上只是极短的一段；成体系的符号大约十万年前出现在洞穴壁画和宗教符号里，书面语言大约五六千年。语言是人类文明的加速剂。2023 年他的第一篇博客标题就是 *Language Agents: A Critical Evolutionary Step of Artificial Intelligence*。现在的 “压缩时间线”——一年顶从前十年——在他看来像同一种加速，只是发生在 AI 里。

那语义解析和 language agent 差在哪？语言一直都在，NLP 也一直在用语言。差在先验。LLM 之前，语义解析每次只能钉死一个数据库、一张知识图谱、一个网站。LLM 给了一个基于语言的世界模型，agent 可以被放进一个它没专门训练过的环境，并立刻产生还算合理的行为。

他拒绝把今天的 coding agent 看成定义更换。编程语言、图表、手势都是符号系统，是自然语言的衍生物。自然语言是人的脚手架，代码是机器的脚手架，但目的一样：描述世界、操纵世界、沟通。形式语言有自己的性质，从 agent 的角度看不是本质区别。所以他不会刻意把 “自然语言 agent” 和 “coding agent” 分成两个物种。

## 五、三年时间线：想法往往很简单，时间点不对就没用

苏煜说自己会偏心，因为他做的是 computer-use agent，不是把 coding agent 的时间线逐篇对齐。下面是他口述的节点，年份是他说的，不是这篇整理重新核定的发表日。

| 时间 | 他标出的工作 | 他给的位置 |
| --- | --- | --- |
| 2022 年初 | Chain-of-Thought | 自适应计算的起点；当时主要在数学题一类推理环境 |
| 2022 年末 | ReAct（姚顺宇） | 把 CoT 放进有外部环境的 agent：感知、推理、行动、环境改变 |
| 2022 年底，约与 ChatGPT 同时 | LLM-Planner（OSU） | 最早用 LLM 做机器人 / embodied planning 的工作之一 |
| 2022 年 10 月启动，2023 年初发布 | Mind2Web | 他认为是第一个基于 LM 的 web / computer-use agent；ChatGPT 是 2022 年 11 月发布的 |
| 约同期 | Google 的 SayCan | LM for robot planning 的代表性工作 |
| 2023 年 2 月 | Toolformer（Meta） | 第一个有代表性的 LLM tool use；他当时在微软兼职，称 Satya Nadella 在全公司传阅，因为对企业软件的含义很大 |
| 2023 年 3 月 | AutoGPT | 交互外壳极简，星标涨得极快（他口述约 10 万，后来约 18 万），实际做成的事极少。他拿来类比后来的 OpenClaw |
| 2023 年下半年 | SWE-bench；GPT-4o | 编程 agent 的基准，以及 agent 转向多模态的时间点。此前工作几乎全是文本 |
| 2023 年 7 月前后 | WebArena（CMU / Graham Neubig） | 比 Mind2Web 晚约一个月。Mind2Web 想做任意真实网站上的 generalist；WebArena 做少数网站的可复现副本，避开网站变动和法律问题 |
| 2023 年末到 2024 年初 | MMMU、SeeAct | 多模态基准，以及基于 GPT-4o 的多模态 web agent。当时 GPT-4o 还没有 API，他们自己把网页界面包成 API |
| 2024 年 3–4 月 | OSWorld（Tao Yu 等） | 从网页扩到桌面 |
| 2024 年下半年 | UGround | 主张 agent 应该 “like humans do” 使用电脑：看屏幕，在像素上点击或输入，而不是依赖 HTML。他认为后来的 Claude computer use、OpenAI Operator 采用的是同类具身 |
| 2024 年 10 月前后 | Claude computer use | 同一具身路线进入产品 |
| 2025 上半年 | OpenAI Operator、GPT agents；Claude Code | Cursor 的影响下，编程 agent 产品化 |
| 2025 年下半年 | Opus 4.5 之后的 Claude Code | 他刚到硅谷，感觉一两月内 “基本上已经不自己写代码了”。扩散到硅谷以外还要时间 |
| 2025 年 11 月出现，2026 年 2 月爆火 | OpenClaw | 他给这条时间线的收束点 |

他反复强调一个方法论：agent 论文看起来往往 “好简单”。ReAct 就是感知—推理—行动。难的是在正确的时间点有那个洞察，并把它做出来。

早期他们会把 browser、desktop、mobile、GUI、text、coding、tool use 分开讲。到这期录制时，他已经把这些都看成临时标签。最后要的是一个 **universal digital agent**：在数字世界里做人能做的事，并且做得更好。浏览器还是桌面、GUI 还是 CLI、API 还是代码，都是 means to an end，而且边界正在快速消失。

Coding 在这里是织物，不是一个垂直赛道。他认可 Dario Amodei 的判断：至少对数字世界，代码是最根本的一层，所有东西最后都能用 code 表达。GUI 本身就是代码渲染出来的，所以可以用代码把 GUI、CLI、API 变成等价物。边界会由 coding 来打破。

## 六、他为什么从语义解析走到 Agent

语义解析在当时的 NLP 里是小众方向。他听过有老师对学生说：做什么题目都可以，别做 semantic parsing——论文更难中，引用更少。他还是做了，因为有一个让他不舒服的观察：软件和网站复杂到普通人要上课才能用。Excel 要培训几个月，AWS Console 有几百个功能、几千条工作流，变成专家要几年。人在变成电脑的奴隶。

博士答辩时他有一句自己也觉得中二的宣言：Let machines understand human thinking. Don't let humans think like machines. 让机器理解人的语言和想法，而不是让人像机器一样思考。数字化分工越细，人就越被要求特异化。语义解析、以及 ChatGPT 出现前他就开始做的 language agent，是同一目标的不同手段。

## 七、OpenClaw Moment：交互变了，权限也放开了

小珺问 OpenClaw 有没有把 agent 往前推进一步。苏煜的答案是：它和 ChatGPT Moment 结构很像，所以重要。

ChatGPT 之前，语言模型已经准备了好几年：BERT（约 2018）、ELMo / AllenNLP 一线（约 2019）、GPT-1 到 GPT-3。OpenAI 做的是把底层模型微调成聊天机器人，直接给公众。底层技术变化不大，变的是交互。研究员自己也没料到一个 chatbot 会这么受欢迎。他顺口提到，这次成功后来也加剧了 OpenAI 内部基础研究与应用侧的摩擦，直至董事会危机。那是后话，他没有展开证据。

OpenClaw 也一样。在它之前，agent 的技术——尤其是 coding 和已有设计范式——已经 ready。做 agent 的人看代码库，很容易觉得 nothing is new。真正变的是两件事：

1. **交互形态。** 可以在 WhatsApp 一类即时通讯里跟它说话；它有自己的环境，24 小时在线。
2. **权限姿态。** 以前学术界和大公司做 agent 都很克制，因为一个能像人一样办事的系统很危险。OpenClaw 把权限和安全开关尽量打开，他用了 “YOLO” 这个词。因为它开源，问题比闭源产品直接这么做要小一些。用户打开权限之后才发现：原来 agent 已经能做这么多事。

所以他把 ChatGPT Moment 看成 LLM 范式被公众确认的时刻，把 OpenClaw Moment 看成高度自动化、个人化 agent 范式被确认的时刻。爆火才一两个月，他已经看到公司路线被牵动：Anthropic 的 Claude Code 在补同类功能（他觉得没有 OpenClaw 也会加上，OpenClaw 是催化剂）；OpenAI 砍实验项目、收束到 agent 和生产力；黄仁勋说每家企业都要有 claw strategy；中国大厂动作很快。裁员新闻和他所说的 “大家对 agent 能力的感知变了” 有关——这是他的感受，不是他给出的因果证明。

他预测再过两年回看，这个时刻的量级可能接近 ChatGPT Moment。这是预测，不是事实。

## 八、中美：开发者圈里的火，和出圈的火

小珺觉得 OpenClaw 在中国更热。苏煜同意，但加了限定：美国也很热，热在开发者和技术圈，大家还在研究怎么做深；中国的叙事已经出圈，街头、地方政府都在谈，甚至被讲成产业机会和个人翻身工具，带一点 “不学就会被淘汰” 的焦虑。美国科技圈之外没有这种辐射。

他听到的一个画面是：子女没时间，老人拿着电脑去活动现场找人帮忙装 OpenClaw。他认为这不只是舆论模式不同，也是应用层速度不同。Eric Schmidt 讲过美国应用层通常更慢。在他看来，AI 时代这会变成中国的优势：基础模型对很多有用的事已经 good enough，大量事情从前做不成是因为摩擦太高、账算不过来；能力一过阈值，这些事情就从 “不值得做” 变成 “值得做”。缺的是能看见这些价值并执行的人。

他不掩饰浪费：有人花钱安装，发现没用，再花钱卸载。对社会整体，他仍觉得是积极的。作为研究者，他立刻把话收回来：从 OpenClaw Moment 到真正的社会影响，中间还缺 “好用、容易用”。现在的门槛仍然很高，多数人找不到价值。他希望每个有独特洞察的人都能把洞察变成能产生价值的 agent。看裁员新闻时，他担心失业速度快过新工作出现的速度。技术民主化是他给研究者的责任，不是一句口号：核心能力如果门槛太高，就只会被少数巨头拿走。

## 九、模型公司会吃掉所有产品吗

小珺问：大模型产品是不是仍然只能由拥有模型的公司来做，因为做应用的公司最后会被模型公司收掉。苏煜说不尽然，而且这和他的公司哲学有关。

如果你要做整个数字世界的唯一入口、一个超级通用的 agent，那更适合模型公司。但他不认为那是唯一机会。世界不是一个世界，是几百万个小世界。每个小世界要产生价值，靠的是专门化，成为那个世界里的专家。大模型公司的组织和商业模式天然推向平台和统一，不推向专门化。这不是愿不愿意的问题，是比较优势：很多专门化在经济上不该由他们做。非模型公司和普通人都还有空间。

## 十、NeoCognition：要的是学会专门化的方法，不是再做一个通用助手

苏煜从高校 unleave（口述；公开资料显示他仍与 OSU 有关联，本文不把人事状态写死），2025 年七八月创立 NeoCognition，到 2026 年 3 月完成种子轮，他口述约 4000 万美元。公司名来自 neocortex：neo 是 “新”，cortex 是新皮层。定位是 agent research lab，长期什么与最终解决 agent 有关就做什么；中短期关键词是 specialized intelligence，不是再堆一层 general intelligence。

他的现状判断：把一个非高度专业、信息也齐的问题丢给 Claude Code、一个还不错的 computer-use 系统或 OpenClaw，大概有六七成概率能做对。通用智能已经在变便宜、变标配。分化来自专门化。每个职业、行业、公司、甚至每个软件和网站都是一个小世界，这些世界的熵几乎无限，没有任何单一模型能装下。所以一定有适应和专门化的过程。他们研究的是怎么建模、抓住并学会这个过程。

方向偏横向，不是死磕几个垂直。自然会更偏企业，因为企业对深度要求更高。

关于 “SaaS 末日论”（SaaSpocalypse），他半信半疑。软件估值逻辑和利润率确实在被压缩，所以股价跌得厉害；但他不相信 agent 会重写或替代所有软件。真正的变化是：软件从前卖的是工具，现在买家要的是结果、劳动力、AI employee。软件公司在自救，想从 tool 转成在自己平台上交付结果的 labor market。AI-native 公司、前沿模型公司和老软件公司谁赢，或者最后达成均衡，他觉得 2026 年才刚开始，说不准。

融资环境他只讲自己的有限观察：2026 年初和 2025 年底已大不相同，两极分化严重。头部新实验室可以一上来融几千万到几亿甚至十亿美元；OpenAI 和 Anthropic 的融资额可能占市场的 30%–50%（他标了 “I don't know”）。中间的 VC 难受，要么变成 a16z、Lightspeed 这种也会投成长阶段的大基金，要么变成有深度知识的精品所。投资人要同时看到：差异化、可信、可做、做成后价值大、而且 OpenAI / Anthropic 不能轻易复制。

他被问得最多的是 “为什么大厂不能做”。他的回答是把做 benchmark 的标准搬到选赛道上。他们组的学生做过不少被模型发布引用的基准（GPT-5.4 发布时他称大约 20 个基准里有 3 个出自组里学生，数字未核实）。他在意的是 construct validity / ecological validity：你测的东西必须和系统最终产生实际价值的方式高度相关，基准才有长寿命。公司也一样。如果一条赛道被解决后会给社会带来根本变化、上限极高，它就不会只有一两家玩家。Expert agent——让通用 agent 有一套学习方法，快速变成各领域专家——一是现在没人能打包票知道怎么做，二是做成了经济价值会非常高。不确定性高、价值高，就会有多条技术路线。他拿机器人做类比：VLA、世界模型、硬件主导，没有人能证明自己是对的，所以大量创业公司在没有交付的情况下仍能融到钱。Agent 现在像那个局面。

## 十一、世界模型比 “下一帧预测” 宽得多

他们的技术路线，他愿意在高层面上讲的词是 world model。当前话语里的世界模型大多是视觉的、物理世界的：下一帧预测、视频预测、三维重建、学一些潜变量再拿去做规划。这些工作重要，也正是语言模型缺的，值得押。但他认为这只是世界模型的一小块。

他用一个实习生举例。第一天进公司，你不知道业务、不知道公司。然后你在工作中学会：名义上的组织架构和实际上谁说了算、做什么要找谁批、软件怎么用、工作流是什么、同事的心智模型。这些一起构成对这个微世界的模型。它显然不是一个视频模型。视觉是一部分，更多是符号的，还有一些既非符号也非视觉。持续学习就是从 intern 变成 expert，也就是建起这个微世界的模型。

这解释了现在 agent 的手感：乍一用很强，六成能做对，三成不知为什么失败。人一旦成为某件事的专家，基本上百分百做对，而且更快、更稳、更省。现在的 agent 不可靠、不高效、还很贵，因为它们在消耗前沿模型的大量 token，却没有这段专门化。

所以目标不是交付一个 HR agent、财务 agent 或法务 agent。那些只是结果。目标是一套持续学习方法：给定任何领域、职业或环境，都能学出一个 expert agent。

现有两条训练路线都不够：

- **模型厂的 RL 后训练**，加上合成环境和 RL gym。速度、准确性和学习范围都和人的持续学习差很远。
- **非参数学习**，像 OpenClaw 和 Claude Code 里的 skills，主要是写 markdown（`soul.md`、`skill.md`），再往 harness 演化。他对这条线有热情，也认为只靠它上限有限。口述里提到的具体 “重写 harness” 工作名听不清，这里不引用。

Continual learning 这个词已经被用滥了。经典设定是：学会新任务，同时别忘掉旧任务。现在它还可以指个性化、用这一代模型开发下一代（recursive self-improvement）、OpenClaw 那种在线积累、以及 RL 后训练。他关心的不是标签，而是学到了什么。在他的用法里，持续学习的目标应该是一个广义世界模型。两个热词是同一件事。

## 十二、新皮层：为什么公司叫 NeoCognition

他把这套想法接到神经生物上，并说明这是假说。新皮层约占人脑 70%，进化上很晚，哺乳动物才有，大约两亿多年前；早期哺乳动物的新皮层很小，到猿类才急剧变大，到人登峰造极。进化时间短，却要承担视觉、语言、听觉、推理、规划等几乎所有和智能有关的事。脑干、海马、小脑进化了远更长的时间，高度特异化。新皮层不是。

他的推论是：进化上最省的办法，是找到一个足够通用的学习机器，做成一个可重复的结构。解剖上也大致如此。功能分区很多，解剖结构高度相似，基本单元是皮质柱（cortical column）。他口述人脑大约由 15 万个皮质柱重复而成——这个数字是口述，未核对。剩下的问题是：同一个结构如何特异化成不同功能，单个皮质柱在学什么。

他最信的理论来自 Jeff Hawkins 的 *A Thousand Brains*（千脑智能）：每个皮质柱都在学世界模型，而且不限于物理世界。语言、数学、民主、法治这些人造抽象概念都是世界模型的一部分。每个皮质柱里有几百个小模型，同一个概念在不同皮质柱里有多份，最后这些模型主导感知、推理和决策。他承认这里不能讲深，也说即使不买下整套理论，人会通过持续学习建立 cognitive maps / conceptual frameworks，这是比较扎实的；agent 的持续学习还远没解决这件事。公司名 NeoCognition 就是从 neocortex 来的。

## 十三、世界模型需不需要语言

小珺提到与谢赛宁的对谈：对方整体偏反 LLM，认为需要更多表征，虽然也承认语言有用。苏煜把自己放在 Chris Manning 附近，分几层说。

视觉极其重要。新皮层里视觉区最大，远大于其他区。但在人类社会里，价值的最大来源仍是语言。人和黑猩猩的文明差距，不是因为人的视力、听力、触觉或运动更好——人的视力大概率不如大猩猩，感知和运动也不是动物里最好的。语言是独一无二的。Manning 的说法他转述为：人和猩猩的差别，不是视觉更敏锐。

他引用 Terrence Deacon 1997 年前后的 *The Symbolic Species*（他记成约 1990 年，年份按通行出版信息理解，不在正文里改成定论）。Deacon 论证从人族祖先到人属，是符号与大脑的协同进化：先有抽象符号表示，再反过来产生进化压力，让大脑更好地产生符号。这等于自己开了一局新游戏。其他物种还在慢速进化，人属打开了一条符号赛道，而且这条赛道是自循环的、偏文化的。一个原始人跑到远处，发现有老虎或有食物，回去用语言告诉所有人——信息越过当下的空间，也越过代际。不能适应语言环境的下一代会失去生存优势。所以语言远不只是沟通工具。

他也认真对待相反的证据。MIT 的认知科学家（他只记得名字首字母 E，很可能是 Evelina Fedorenko，本文不把论文归属写死）用 fMRI 论证 language and thought 可以分离：人在做复杂推理时，韦尼克区和布洛卡区不一定亮。他接受这个分离。解释是：个体思考时，语言可以已经不在场，因为学习就是把一度需要语言脚手架的知识内化成神经元之间的直接连接。睡觉、做梦、海马把短期记忆转成长期记忆，都和这个内化有关。语言和思维可以分开，不代表形成那些表征时语言没起作用。

再把镜头从个体拉开：任何现代工业，尖端的或不尖端的，都建立在符号、图表、编程语言上。他在推特上说过、Manning 也赞同的一句是：individual thought doesn't need a language, but civilization needs a language.

因此，即使有一天底层模型不再是 LLM，而是某种未来的世界模型，以语言去理解、推理、并与世界交互的能力也不会消失。Language agent 这个词可能会变得多余——大家默认 agent 就该有这种能力——但能力本身不会退场。这是他仍坚持 “language agent” 这个名字的原因。

## 十四、GUI 不会消失，CLI 也不会统一世界

最近的争论是：agent 和电脑的交互，未来是 GUI 还是 CLI。他的总判断仍然是手段之争，终点还是 universal digital agent。往下拆，他有四笔账。

**GUI 会不会消失？不会。** 人是视觉动物，大脑就是这么编码的。HCI 研究里，把同一件事可视化，理解会快零点几秒。GUI 对校验、建立信任、审计也有实际好处。

**Agent 要不要 GUI？短期甚至长期都要。** 图形界面是数字世界事实上的界面，绝大多数东西已经能用 GUI 操作。界面里编码了知识、约束和业务逻辑。用得好，就是在已有积累上搭便车（piggyback），而不是重做一套 CLI/API。长尾场景尤其如此：大软件公司有能力重写接口，长尾不会。另外，文本是一维表示，很多复杂关系用二维或更高维的视觉表示更高效。

**社会和人性的账：Semantic Web 是反例。** Tim Berners-Lee 做完万维网后推动语义网，要用明确的逻辑语义描述整个互联网，还配套了描述逻辑。技术上看起来美好，推了二十几年，采用率仍然很低。社会不是 “我有一套更优标准，世界就会重写” 这么运转的，除非到处都有足够强的激励。GUI 有这个激励，因为人需要它。指望所有行业几年内采用 MCP，或把系统重写成 CLI，几乎不可能。关键基础设施到今天还跑在几十年前的 COBOL 上，也不会变得那么快。

**局部最优的经济账。** 即使能证明 “全部 CLI 化” 对 agent 是全局最优，也不是每个局部的最优。很多地方现有方案已经够好，不值得为了全局最优去换。

所以他不认为 CLI 会全面取代 GUI。这是对交互路线的判断，不是对某家产品的背书。

## 十五、2026 年的瓶颈：可靠性、速度、成本是同一件事

小珺问瓶颈是 self-learning、memory，还是别的。苏煜把这期讨论收成一句话：memory、self-learning、continual learning、world model、specialization、expert agent 是同一件事的不同侧面。

持续学习是过程，世界模型是学习内容，专门化、成为专家是结果。结果会带来现在 agent 最缺的东西：可靠性、速度、成本效率。2026 年他预期的主旋律就是 continual / self-learning。至于是不是他这种 “以世界模型为目标” 的持续学习，只是诸多押注之一。

和这件事绑在一起的，是这套技术能多快辐射到社会角落。可靠性、速度、成本和门槛，也解释了为什么 OpenAI、Anthropic 要采用他所谓的 Palantir 模式：招大量 forward deployed engineers，驻场帮客户搭 agent。那是能力还没专门化之前的补丁。

安全他拆成两层。很多 safety 问题是能力问题：实习生比老师傅更容易犯安全方面的错，因为老师傅已经知道哪些动作有风险。Security 不完全一样，它是更坏情况，需要专门方法，不能只靠 “变熟练”。

长程任务不稳定，他同样归到世界模型：系统对这件事不熟，做过也没有像人一样把经验变成专业的一部分。

## 十六、大厂在押什么：去年还在分叉，今年在抄作业

他觉得大厂曾经押得很不一样，现在高度统一，因为 Anthropic 暂时一家独大，而且给所有人打了样。今年和去年最大的不同是：很多方面已经是在抄作业。去年年底之前，这一点远远没这么明朗。

他点到的差异，按口述记录，不把传闻写成事实：

- **Anthropic**：和生产力相关的都做。
- **OpenAI**：往生产力、agent 收束。
- **Google**：模型强，生态位好，但采用和叙事上 “总觉得缺了点什么”。他承认没看清更深层的原因，小珺补了一句 “缺应用”。
- **xAI**：马斯克对 computer-use / GUI agent 很有热情，成立 Macrohard，想用 agent 取代软件、做知识工作。内部动荡会影响到这条线。技术上他猜测会偏特斯拉 FSD 的路：较小的模型、以视觉和视频为主、端到端。至少是一个不同的押注。他说 good luck，没有判断成败。
- **Project Prometheus**：Jeff Bezos 重新回到 operator，任 co-CEO。口述融资约 60–70 亿美元；公开报道在 2025 年 11 月写的是约 62 亿美元起步，后来的轮次更大。苏煜说他们更低调，有很大一块 computer-use，最终想做的偏制造、物流、基建和工厂，那是 Bezos 熟的部分。
- **中国**：字节的 UI-TARS 系列和豆包手机，阿里的相关工作，智谱很早开始的 computer-use / AutoGLM。他和唐杰认识多年，2023 年夏天 Mind2Web 做完后去清华讲过，后来合作了 AgentBench，是早期 agent 基准之一。OpenClaw 之后，他认为大家都会有自己的 claw strategy。

Computer use 这个词本身也在变宽。以前它几乎等于 GUI 操作；现在做 CLI、tool use 的，也渐渐被划回 computer use，慢慢变成 general digital agent 的同义词。

## 十七、为什么这个时间点离开学校

他强调这是个人观点。他喜欢学校。以前在微软有全职，收入比学校高三四倍，还是去了 OSU，因为学校允许他同时做十个奇怪的想法，公司里可能只能做一两个。钱不如这个重要。

从学校到创业，动机在他看来是同一类：agent 已经走过了 proof of concept。早期一个想法可以用精巧、低成本的方式证明，然后说服领域。从 2025 年开始，有意思的 agent 想法需要的资源变了——GPU、大量 API、以及能快速试错的团队。这和学校的基因不匹配。所以这个时间点有不少老师出来。

创业半年，节奏和内容都根本不同，但他喜欢学新东西。他自认不是想得很快或记得很好的人，长处是把很多东西串成 conceptual framework。创业环境给了他新的刺激。如果是普通 startup，激励结构会完全不一样：要快速做市场验证、取悦客户和投资人、找到 PMF、做大。学术界在经费够的时候，这些约束少得多。可迁移的部分是：助理教授从第一天就是管理者，要拉钱、拉人、管成长和产出，和管一个研究型创业公司有相似处。

NeoCognition 仍是 research lab 气质，所以落差没那么大。他一直知道自己会做 startup，因为 agent 做到一定程度后，研究和部署分不开。他相信下一阶段最大的学习信号来自 deployment 里的持续学习：没有部署就没有学习，学校很难提供那种部署。几年前他们就可以成为最早的 agent 创业公司之一，但他当时觉得没 ready——环境的技术根基没 ready，自己对瓶颈的认识也没 ready。到 2025 年年中，语言模型、tool use、coding、多模态都开始够用，他对瓶颈也有了更硬的判断，才出来。

失败了就换个地方继续做研究。他不太想后路。美国的退出通道确实更多，VC 和大厂之间有关系，可能帮着找后路，但他不确定，也不是决策因素。

## 十八、成长经历：读书是在造世界

这部分是快问快答里展开的个人史。他自己在结尾要求不要把它当成对小朋友的不良引导：逃课、高强度打游戏不是值得提倡的事。本文保留，因为它解释了他为什么把 “构造世界模型” 当成个人长处，同时按他的要求标明界限。

他不是典型的好学生。会凌晨三点从家里溜去网吧，后门敲开老板睡觉的地方，玩到七点再去上学。玩的方面没怎么耽误，一件坚持得很好的事是读书：家里任何纸质的东西都读，历史、政治、故事会、言情小说。读书就是在脑子里构造一个个世界，并构造世界之间的关联。这件事塑造了他的学习和人格。为什么爱读书，他已经不记得了。

县城出身，教育资源一般。平时不是一门心思扑在学习上，但有明确考试时会在自己认为需要的时间点全力准备。湖南自主招生、高考他口述为全省前列，清华降分录取的资格最后没用上，但改善了心态。家庭条件不算好，奖学金很重要。

他给自己的性格起名 “浑不吝”：不会为了想要的东西吃不好睡不好；同时知道，如果真把心思和力气放上去，大概率做得成。这个组合出现在博士、做老师和现在的创业里。

## 十九、预测、风险，以及研究者该做什么

技术预测他愿意说死一句：continual learning 会在未来几年被解决，agent 会广泛渗透，根本改变很多行业的生产关系。这个改变是可控还是不可控，是现在做 AI 研究的人的责任。

他看不到可预见的未来里，AI 会撞上奇点、自我迭代到远超人类然后取代人类。那个场景缺的不只是智能，而是原生目标、意图和生存压力。至少现在，他没看到把这些原生意图注入 AI 的路径。现在的目标仍然是被赋予的。

他真正担心的是 job displacement。如果 agent 大规模取代知识工作，又不能产生足够多的新岗位，也没有收益再分配给社会兜底，收益集中在少数公司和资本手里，社会会出大问题。说 “尽一份力” 他觉得有点矫情，但是真实感受。

他给自己的那一份是：democratize access to frontier agent capabilities。专家级 agent 不应该只有头部公司的资本和资源才能做。一个人如果有独特洞察，应该有足够可及的技术手段，把它变成 agent，并且能从中获得收入。

## 快问快答

- **食物**：火锅。
- **两本必读**：Max Bennett 的 *A Brief History of Intelligence*（2023）。他刚出版就买了，读完推荐给实验室所有学生，认为是把 AI、进化和神经科学接得最好、又最通俗的一本。书中 “Mice in the Imaginarium” 和试错学习的章节，直接影响了他们后来的论文 *LRMs in the Imaginarium*（在模拟试错中学习使用工具）。第二本是 *A Thousand Brains*。理论大胆，证据还早、还粗，但以他读过的生物学材料看，很 make sense。
- **影响 AI 进程的论文**：不限定近十年的话，他会从 1943 年 McCulloch-Pitts 的神经元计算模型说起（名字他没记住），那篇把单个神经元的工作用计算模型抓住，后面的神经网络和 biologically inspired AI 都从这来。图灵不须多说。反向传播是 Hinton 等人把它大众化的工作，不一定是最早的表述。AlexNet（2012）是神经网络文艺复兴；word2vec（2013）把神经网络重新引进 NLP——在那之前 NLP 对神经网络近乎嗤之以鼻，而 2013 年正是他开始做相关工作的时候。BERT（2018）是第一个大规模预训练的语言基础模型，改变了语言处理的范式；年轻一代因为 GPT 可能已经不知道它。Transformer（2017）不是凭空出现的：2014 年就有序列到序列和 NYU 机器翻译里的选择性注意，残差来自 ResNet，ResNet 又来自更早的 highway networks。再往后是 GPT 系列对产业格局的影响，以及 Chain-of-Thought、Toolformer 各自的影响。
- **当下最重要的押注**：all the way continual learning, all the way world modeling。
- **听过小珺的播客**：以前听得更多。最近听了谢赛宁那期的一部分，七小时太长，听了两次还没听完。还听过杨植麟、姚顺宇，以及一些更偏创业的。

## 结语

这期如果只记产品名，会误以为主题是 OpenClaw。苏煜实际在做的是把一个被用滥的词按回六十年的问题：一个有边界的实体，如何在复杂环境里有目的地行动。逻辑智能体死于表达力和知识获取；游戏里的神经智能体把一件事做深，但计算量不随难度变化；语义解析想把话说成可执行的形式，却没有一个能带去任何环境的先验。语言模型补上的是脚手架，不是魔法。

第二条主线是：通用能力变便宜之后，价值从 “什么都能试” 挪到 “在一个小世界里变得可靠、快、便宜”。记忆、持续学习、世界模型和专家智能体在他的框架里是同一件事。GUI 对 CLI、模型公司对创业公司、中国应用速度对美国开发者圈，都是这条主线的推论，不是并列的热点。

第三条主线是责任边界。他不把近期风险写成奇点，而写成岗位置换快过新岗位和再分配。他开公司的理由也从这里来：没有真实部署，就没有他想要的学习信号；如果专家级 agent 只有巨头做得出，技术民主化就是空话。这些是他的押注和立场。数字、融资和 “谁在抄谁” 都还是口述，回到原始分段之前，不要把它们当成已核实的行业事实。
