# DeepSeek

中国前沿 AI 实验室，由 **[[liang-wenfeng|梁文锋]]** 创办（约两年前起步，「没有很多钱、没有很多卡、没有知名度」）。**目标是 AGI**，商业化只是路上的副产品。本页依据 [[liang-wenfeng-investor-meeting|梁文锋投资者交流会全文]]。此前在本 vault 仅作为「DeepSeek V4」在 [[ai-native-company]] 的 cross-modal eval 里被顺带提及。

## 定位：只做 AGI 主线

- **只做「智能主线」**：语言模型 → CoT → Agent → 持续学习（见 [[agi-roadmap-ladder]]）。**明确不做** 3D、视频生成、世界模型——「跟智能的上限没有太大关系」（虽然视频生成「在商业上是个好生意」）。
- **多模态 = 组件**，不是主线本身（像搜索一样是组件）；**V4 后续版本会支持原生多模态**。
- **C 端 / B 端 = AGI 的副产品**：「我们做 AGI 是为了做 AGI，刚好能产出这个东西，就拿来商业化了。」几个人维护 API，甚至没有客服、销售。

## 商业模式：只赚合理利润

- **定价 = 十个月回本 ≈ 6 倍利润**（V3.2 Flash 等按此定价）；不是利润最大化。见 [[restraint-as-strategy]]。
- **开源（含最强模型）**：「我看不到闭源什么好处。」开源模型 = 自部署模型，不留一手。为什么不冲突商业——见 [[open-weights-strategy]] 的 DeepSeek 段（AI 市场太大不可独占 + 部署门槛 + 十个月回本让第三方无利可图）。
- **现金流**：今年 B 端 ARR 有望做到几亿美金；若达十亿美金，现金流转正、cover 研发。「最坏情况全力卖 API，也够支撑一个上市公司。」
- **唯一核心利益 = 团队稳定性**（见 [[liang-wenfeng]]）。

## 算力现状（见 [[china-us-compute-gap]]）

- 现约 **2 万张 H 等效算力**（大部分最近一两个月刚到），激进扩张、基本买英伟达，也买「不合规的卡」；策略是「合理价格能买多少买多少」。
- 现做 **50B 激活**规模；下一代目标 **150–250B 激活**（乐观今年底开训）。美国前沿 ~800B 激活，DeepSeek「训不起、也用不起」。
- **华为合作**：拿到约 **1.6 万张华为 950**（≈4 千张 B 系列），目的主要是帮华为**把国产生态做好**；产能是唯一瓶颈。
- **TileLang**：自研高级语言，用来写 CUDA 算子；**V3 训练已「用英伟达卡但不用英伟达生态」**，只需在华为卡上把这套重做一遍即可迁移；效率不降反升（损失 1–2% 可接受）。

## 技术判断

- **信 Scaling、没看到墙**：「阻止我们 Scaling 的其实就是算力」；模型大小是按资源倒推的，不是「够了」。见 [[scaling-laws]]。
- **下一代模型的核心能力 = 持续学习**；在那之前只能做成本更低、效果更好、速度更快。
- **模型首先服务自己**：下一版模型第一目标不是用户好用，而是**提升 DeepSeek 自己的研发效率**→ 加速 AGI。
- **一半核心研究员在标数据**：数据≈模型的一半；中国在高端标注上无成本优势，瓶颈是时间。
- **幻觉**：可通过更好的 post-training 改善，归为**产品问题**，非重点。
- **发版节奏** ~2–3 个月一版。

## 组织

- **无固定组织架构**（愿景驱动），但随人员扩大**正在做调整**——部分部门会建立严谨层级，部分维持扁平松散。
- 与 **Bell Labs 的区别**：Bell Labs 不需商业化，DeepSeek「归根结底是一个公司，政府不会给一分钱，必须能活下去」。

## 对三大实验室与格局的看法

- **Anthropic** 在 Code Agent 的先发优势「**不是长期的**」、很快会没；**OpenAI 与 Google 会交替上升**；三家是全球**效率最高**（烧钱最少）。
- 大模型公司**不可能拿走大部分利润**，最终差距只在**成本 > 时间 > 体验**，会**收敛**到三四家。
- 中国大概率是全球 AI 的「**三体之一**」，扮演**产量最大 / 最便宜**的角色（产能、电力最多）。见 [[sovereign-ai]]。
