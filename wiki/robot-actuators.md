# 机器人执行器：减速器、电机与伺服系统

执行器（关节）是人形机器人**成本最高、技术最密集**的部件，约占整机成本 **51%**（美银测算），是量产降本的核心战场。

---

## 执行器分类

### 旋转执行器

结构：**伺服电机 + 减速器**

肩关节需要三自由度（俯仰/滚转/偏航），用三个旋转执行器组合实现；膝关节通常只需一个。当前**量产最主流**的方案。

### 直线执行器

结构：**伺服电机 + 丝杠**

模拟人体肌肉（推拉而非旋转），常用于膝关节辅助或手腕/脚踝多执行器组合以实现旋转。

| | 旋转执行器 | 直线执行器 |
|---|----------|----------|
| 量产成熟度 | 高 | 低 |
| 动态性能 | 好 | 差（减速比大） |
| 载荷 | 中 | 大 |
| 自锁能力 | 无 | 有（断电保持姿态） |
| 成本 | 相对低 | 高 |
| 商业化状态 | 主流 | 尚不适合大规模商业化 |

> 直线执行器的核心难题：丝杠加工精度极高，长行程内一致性要求严苛，批次间差异导致控制算法调适成本大。

## 减速器深度拆解

电机天生"高转速、低扭矩"，减速器通过牺牲速度换取力矩，是旋转执行器的核心精密部件。

### 三大类型

#### 行星减速器
- 结构：太阳轮 + 三个行星轮 + 外圈齿轮
- 特点：**结构小、成本低**，但减速比小（输出扭矩较低）
- 应用：**手部关节**等低扭矩场景

#### 谐波减速器（Harmonic Drive）
- 结构：波发生器（椭圆凸轮）+ 柔轮 + 刚轮，柔轮与刚轮差 2 齿
- 原理：波发生器旋转一周，柔轮只转 2 齿 → 极大减速比
- 特点：**高精度、高输出扭矩**；但柔性结构→**抗冲击弱**
- 应用：**肘关节、肩关节**（精准控制手臂）

#### RV 减速器
- 结构：第一级行星齿轮 + 第二级摆线针轮
- 原理：摆线盘多齿同时啮合，刚性高
- 特点：**减速比大 + 高刚性 + 强抗冲击**
- 应用：**髋关节、膝关节、腰部**（高冲击部位）

### 减速器的"不可能三角"

```
        高性能
       /      \
      /        \
低成本  ——————  长寿命
```

> "性能又好、成本又低、长时间又没问题、摔倒又能抗冲击——这就是非常有挑战的事，感觉是个不可能三角。"

量产关键不是"造一个减速器"，而是**造一万个性能一致、耐用的减速器**：
- 使用 1000h 后开始异响、性能退化 → 步态变歪
- 极限动作冲击 → 内部小齿轮损伤
- 精密齿轮加工难度高，长期稳定性难以保证

### 代表供应商
绿的谐波、双环传动、中大力德（均为国内）

## 电机与伺服系统

### 电机类型
- **无框力矩电机**：去除外壳和轴承，只保留核心，直接嵌入关节；主流选择
- **空心杯电机**：体积极小，用于**灵巧手**（输出功率相对低）

### 三大挑战

#### 1. 能效与散热
- 极限动作时瞬时电流达平时 3-5×，发热量 = 额定状态的 **9-25×**
- 发热非线性：做一次空翻，关节温度可从 +10℃ 直跳 +50℃
- 早期样品：极限动作只能做一次，需等温度降下来再做
- 3% 与 5% 发热率的差异：看似小，实则制约整体性能上限
- 被动散热为主（金属机身当散热片）；腿部等高功率关节加风冷/液冷

#### 2. 体积限制
- 体积越大 → 转动惯量越大 → 改变运动状态越难（类比绳子越长越难快转）
- 工程师持续压缩关节电机尺寸

#### 3. TN 曲线稳定性
- TN 曲线：输入电流 → 转数/扭矩的映射关系
- 不稳定的 TN 曲线 → 控制指令相同但执行输出偏差 → 摔倒
- 仿真训练用的 TN 曲线若与实机不符 → 仿真 sim-to-real gap 扩大

### 伺服系统组成
- **编码器**：测量转子角度/速度/位置；旋转执行器需**双编码器**（输入端 + 输出端）才能精确控制
- **驱动器**：根据编码器反馈 + 小脑指令，动态调整电压/电流
- **传感器**：力矩传感器（输出扭矩）、温度传感器（防过热）等

## 自研 vs. 采购

| | 采购成品执行器 | 自研执行器 |
|---|---|---|
| 优点 | 研发成本低、开发快 | 高度匹配需求+算法，性能更强 |
| 缺点 | 物料成本高，难以定制，性能受限 | 研发周期长，人力投入大 |
| 适用 | 小团队/快速出样 | 头部规模公司 |

> 头部机器人公司（智元等）倾向自研，甚至**驻场供应商参与设计**。
> 执行器是未来量产降本的关键，中国供应链内卷已能替代大部分进口精加工件。
