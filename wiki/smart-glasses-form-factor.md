# 智能眼镜形态：重量、配重、续航

智能眼镜是否"可全天佩戴"几乎完全由形态因素决定，与软件无关。[[dianwan-keji-ak]] 作为重度使用者（每天混戴 3-4 副）提供了一组现实参数，揭穿了行业内"14.9g 全球最轻"等营销话术。

## 重量底线（2026）

按拆解实测：

| 组件 | 重量 |
|------|------|
| TR90 镜框 + 铰链 + 鼻托（理想 Livis 壳，无电子件、无镜片） | **20 g** |
| 处方镜片（650-750 度，1.74 折射率） | **10-15 g** |
| 处方镜片（1.6x 折射率，更经济） | **15-20 g** |
| Meta Ray-Ban Wayfarer 整机 | ~50 g |

**结论**：
- 镜框**做到 20g 是工程极限**（短期内）
- 处方镜片 10-20g 是物理定律
- 单镜片单元的整机底线 **30g (无镜片) / 50g (含中等度数镜片)**
- **任何号称 14.9-20g 的"全球最轻智能眼镜"营销话术，都不算镜片或处于手板阶段**

## 配重比重量更重要

重量只是单一指标。真正的佩戴体验取决于：

1. **Weight Distribution（重量分布）** — 前后是否均衡，前重则压鼻
2. **挂耳结构** — 后端能否勾住耳朵不让眼镜前移
3. **鼻托** — 高度和接触面（用户脸型差异巨大）
4. **夹持力** — 镜腿对头部的横向压力

### 反人因的常见错误
- 鼻托不调，戴上去切眉毛（[[dianwan-keji-ak]] 看到很多用户没调整就长期戴）
- 加第三方粘鼻托——丑、易脱、不治本
- 试图通过加高鼻托解决下滑——错的方向

### 治本方法（Scriber/Blayzer 范式）
- 可形变镜腿（金属梁 + TR90）按耳形塑形
- 后端能挂住耳朵，眼镜不会前移
- 即使鼻托不够高也不下滑

详见 [[meta-ray-ban-scriber-blazer]] 的可形变镜腿与可换鼻托。

## TR90 材料

智能眼镜镜框主流材质：
- 工程塑料尼龙
- **本身可形变**（壁厚薄、有弹性）
- 安全：不易折断，可大力按压
- 表面可做磨砂 / 高亮两种处理
- [[dianwan-keji-ak]] 推荐磨砂，理由：不留指纹、不显油脂、不易划痕

## 双眼镜轮换策略

[[dianwan-keji-ak]] 多次强调，2026-2028 年的**续航最优解是双眼镜**：

- 即使 [[ar1-plus-chip]] 显著省电，一副 Meta Ray-Ban 也**撑不过一天**
- 早上戴出门 → 下午 3-4 点没电
- 这是芯片做到 10 小时续航也无法解决的（醒着的时间 ~16 小时）
- 包里随身：眼镜盒 + 第二副在盒中充电
- 一副戴脸上、一副在盒里轮换

预测：**至少未来 2 年，单眼镜全天用是不可能的**。

## 拍摄提示灯

新款 Scriber/Blayzer 的拍摄指示灯比 Gen 1/Gen 2 缩小 40%，"被拍人"几乎察觉不到。这与隐私监管趋势相反——Meta 选择降低可见性而非加强警示。
