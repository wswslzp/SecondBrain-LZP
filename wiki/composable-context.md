# Composable Context

[[brett-goldstein]] 提出的万亿美元级基础设施机会：构建可组合的全球上下文层。

## 问题

当前构建上下文基础设施如同在荒漠种地——需要从零搭建数据库、ingestion pipeline、检索系统。信息被平台割裂：

| 平台 | 组织的信息 |
|---|---|
| Google | 世界的网页 |
| Meta | 世界的人 |
| LinkedIn | 世界的职业关系 |
| Salesforce | 世界的交易 |

## 可组合性的历史意义

**Composability**（将独立组件组合为新系统的能力）是几乎每一次技术革命的催化剂：
- 标准化零件 → 工业革命
- TCP/IP → 互联网
- API → SaaS 生态

## 愿景

> "The Intelligence Revolution will be catalyzed not by intelligence itself, but by composable context."

从孤立的 MD 文件和公司级 brain，演进到**全球统一的上下文层**：
- 服务数百万 [[agentic-micro-company]]
- 驱动数万亿 agent
- 任何信息、软件或商业结果 = **一个 prompt**
