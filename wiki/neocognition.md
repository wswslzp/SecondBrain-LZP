# NeoCognition

[[yu-su|苏煜]] 2025 年七八月在硅谷创立的 agent research lab。名字来自 neocortex（新皮层）：进化很晚、结构可重复、却承担了几乎所有与智能有关的功能。他用 Jeff Hawkins 的千脑智能作类比——皮质柱在学广义世界模型——但把这当作假说，不是公司的技术规格。

## 做什么

长期：凡是与最终解决 agent 有关的问题都可能做。中短期只押一件事：不是再做一个通用助手，而是一套持续学习方法，让通用 agent 在任意领域、职业或环境里变成专家。他称为 [[specialized-intelligence|specialized intelligence]]。

他明确说，产出某一个 HR、财务或法务 agent 不是目标。那些是方法跑通之后的结果。

## 为什么现在做

他相信下一阶段最大的学习信号来自真实部署里的持续学习。学校给不了这种部署。2025 年年中，他认为底层的工具使用、编程和多模态能力开始够用，自己对瓶颈也有了判断，才出来。几年前就可以做“最早的 agent 创业公司之一”，他当时觉得没 ready。

访谈中他说种子轮约 4000 万美元，2026 年 3 月前后完成。这是口述，未独立核实。公司偏横向，自然更靠近对企业深度有要求的场景，不把自己绑死在几个垂直行业。

## 和其他路线的差别

- 模型公司适合做数字世界的唯一入口。专门化与它们的平台模式和比较优势冲突，所以不是唯一机会。
- RL 后训练和非参数的 skills / markdown，他都认为还没解决“学会一个小世界”。
- 视觉世界模型（下一帧、三维重建）重要，但是世界模型的子集。公司组织、工作流和他人心智也是模型的一部分。
