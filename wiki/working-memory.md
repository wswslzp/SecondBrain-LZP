# Working Memory

Baddeley & Hitch (1974) 提出的工作记忆模型，替代了简单的"短时记忆"概念。不是被动存储，而是**主动操作信息的工作台**。

## 四个组件

1. **中央执行系统** (Central Executive) — 注意力调度器，决定关注什么、忽略什么
2. **语音环路** (Phonological Loop) — 内耳（1-2秒保持）+ 内声（默念维持）
3. **视空间画板** (Visuospatial Sketchpad) — 处理视觉和空间信息的心理画板
4. **情景缓冲区** (Episodic Buffer, 2000年补充) — 整合多源信息为连贯体验

## 关键属性

- **容量**: Miller (1956) 的 7±2 项，Cowan (2001) 修正为 4 个组块
- **压力影响**: 焦虑占用中央执行系统资源，降低效率
- **可训练性**: 直接训练迁移性差，实用策略（分块、外部辅助）更有效

## AI 类比

工作记忆 ≈ LLM 的**上下文窗口** (context window)
- 容量有限（token 限制 vs 7±2 项）
- 主动操作信息（推理 vs 心理运算）
- 差异：AI 缺少灵活的注意力调度（中央执行系统）
