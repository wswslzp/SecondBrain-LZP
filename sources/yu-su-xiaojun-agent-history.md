# 苏煜 × 张小珺：Agent 技术史、OpenClaw Moment 与边界的消弭

## 核心判断

- **Agent 不是新词。** 有边界的实体、处在环境中、做有目的的活动。用记忆和自主两条轴，可以同时评价逻辑智能体、游戏 agent 和语言模型。
- **这一代应叫 language agent。** 语言是脚手架：撑起理解、让计算量随难度变化的推理，以及在数字世界里行动。编程语言仍是语言，不是另一个物种。
- **终点是 universal digital agent。** 浏览器、桌面、GUI、CLI、API 都是正在消弭的手段。GUI 不会消失，因为人需要它，长尾软件也不会为了 agent 重写。
- **OpenClaw Moment 像 ChatGPT Moment。** 底层能力已经就绪，变的是交互形态和权限姿态，不是新算法。
- **通用智能变便宜之后，差别来自专门化。** NeoCognition 要的不是某一个垂直 agent，而是能在任意小世界里学会专家模型的持续学习方法。
- **可靠性、速度、成本大多是同一缺口。** 系统没有像人那样把一个微世界学成自己的专业。
- **近期风险不是奇点，而是岗位置换。** 他给研究者的责任是把专家级 agent 的门槛降到个人能用洞察变现。

## 关键机制

| 主题 | 嘉宾框架 | 需要保留的边界 |
|---|---|---|
| 历史分期 | logical agent → neural agent / semantic parsing → language agent | 年份是口述，不是重新核定的发表日 |
| OpenClaw | 交互变了，权限从克制变成 YOLO；开源降低了直接放开的风险 | “再过两年量级接近 ChatGPT”是预测 |
| 专门化 | 世界由几百万个小世界组成，单一模型装不下其熵 | 六七成成功率是手感，不是基准 |
| 学习目标 | continual learning 的目标应是广义 world model，不只是下一帧预测 | Jeff Hawkins 的千脑理论被当作假说 |
| GUI / CLI | GUI 搭载已有知识和业务逻辑；Semantic Web 说明更优标准不会自动被采用 | 不判断某一家 CLI 产品的生死 |
| 创业时机 | 2025 年后有意思的 agent 研究需要部署带来的学习信号，学校给不了 | 种子轮 4000 万美元等数字未核实 |
