## Summary

Brett Goldstein 提出"Context Farming"将成为人类在 AI 时代的最终职业。核心论点：AI 智能已超越人类，人类的价值不再是做决策或执行工作，而是为 AI 提供高质量上下文。由此催生"Agentic Micro Company"（AMC）模式——极小团队 + 大量 agent + Company Brain，已有创业公司用此模式数月内从零做到千万美元营收。

## Key Points

- **Context > Model Size**: 小模型+好上下文可以击败大模型。当前 agent 是"有严重失忆症的量子物理学博士"
- **Agentic Micro Company (AMC)**: 极小团队通用人才 + 大量 agent + 定制软件 + Company Brain
- **Company Brain**: 所有公司信息汇聚一处，agent 以此为"大脑"运行业务
- **Context Farmer**: 人类角色从执行者转为"上下文农夫"——监控上下文质量衰减、从物理世界采集新信息
- **Karpathy 2026/4/2 的 knowledge graph 帖子** 催化了行业对统一记忆系统的认知
- **万亿美元机会**: 构建可组合的全球上下文层（Composable Global Context），打破 Google/Meta/LinkedIn/Salesforce 等平台的信息孤岛
- Block (Jack Dorsey) 裁员 40% 重组为小团队+agent 模式
- Garry Tan 的 GBrain 等开源工具涌现
