# You need to be delusional if you want to succeed

[[dan-koe]] 的核心命题是：目标不只是终点，也是决定你注意什么、忽略什么的过滤器。文中的“delusional”是夸张的目标设定修辞，这里提炼为**用自选的高挑战目标改变路径选择**，不赋予临床含义。

## 论证主线

- **忙碌不等于进步**：社会、家庭或同伴默认的目标可能支配日程，即使个人没有主动选择它们。
- **目标改变信息筛选**：如果只盯着熟悉的线性路径，就可能忽略产品化、合作和分发等不同解法。
- **挑战旧方法，而非只增加工时**：结果与期限若让原有做法失效，才会促使人寻找新的杠杆。
- **动力来源**：作者列出好奇心、热情、意义、自主和精通；具体激素与神经可塑性解释属于其通俗论述，不当作经过本文证明的机制。

## 作者的三步法

1. **安装视角**：选择超出现有习惯与能力、具有强时间约束的单一自主目标。
2. **设立不做清单**：审视项目、客户和日常活动，减少无助于目标的投入。
3. **寻找高杠杆路径**：识别真正限制结果的环节，寻找能改变规模的产品、工具或合作。

作者自述的例子是：将社交帖子从“产品”改为分发渠道，另设付费产品，并通过与更大受众的创作者交换价值扩大触达。具体收入目标和经历是个案，不是可复制收益承诺。概念化见 [[goal-directed-attention]]。

## 与既有材料的张力

与 [[agency]] 一致之处是主动选择目标、敢于尝试和寻找真实优势；分歧是本文鼓励极端聚焦并审查几乎所有生活投入，而 Cate Hall 强调防止倦怠、维持探索。可保留挑战旧方法的作用，但不能由此推导应牺牲健康、关系或必要义务。

“现实目标必然失败”与“未达成也至少接近”都是作者的强修辞，缺乏本文中的系统比较证据。目标过高也可能导致资源耗尽，应与 [[judgment]] 的反馈和风险约束并用。
