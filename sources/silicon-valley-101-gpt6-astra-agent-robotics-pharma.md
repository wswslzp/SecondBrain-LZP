# E256｜Agent、机器人与制药，谁先被GPT-6 Astra改写？

**来源**：《硅谷101》播客第 256 期（YouTube `lsANSvYQks0`，2026-10-20 发布，录制于 2026-09-29，全长 1:19:40）

主持人泓君对话三位分别站在 Agent、具身机器人与生物医药 AI 一线的研究者兼创业者：清华大学交叉信息研究院助理教授、破壳机器人创始人 **[[huazhe-xu|许华哲（Harry Xu）]]**，**[[zheqing-zhu|朱哲清（Bill Zhu，Pokee.ai 创始人兼 CEO）]]**，以及华盛顿大学计算机学院助理教授、Apodex 首席科学家 **[[sheng-wang|王晟（Sheng Wang）]]**。节目围绕 [[openai|OpenAI]] 发布 **[[gpt-6-astra|GPT-6 Astra]]**（Greg Brockman 宣称“AGI 已经到来”）以及 2026 年 9–10 月的一系列密集行业事件（Meta Muse 登顶 App Store、Instinct 估值跳涨至 100 亿美元、TypeSafe 的“系统1”概率模型 Jev 融资 8.7 亿美元、Claude 21 小时发现类 CRISPR 的 ART 新酶系统、Biohub 将虚拟细胞计划扩至 18 亿美元），深入剖析了三个赛道的真实瓶颈：**个人 Agent 商业化卡在云端 IP 封锁、身份验证与高昂 Token/沙箱烧钱成本；机器人迎来“来自 GPT 自身的 GPT 时刻”，分层控制边界被下压，但受制于长 CoT 延迟、直觉物理缺失与双臂灵巧短板；AI 制药的干实验代码题已被攻克，真正的卡点在湿实验周期（小鼠与猕猴代谢）及实验方案设计（当前完成度仅约 30%）的“[[wet-lab-verification-loop|Human Use（人类/湿实验调度）]]”。**

## 一句话

模型层的能力曲线虽已能跨界碾压机器人仿真榜单、操作生物医学老旧软件并解出干实验代码题，但决定一个行业何时真正被改写的不是纯智能，而是**现实世界的验证与准入闭环**——Agent 要过商家身份与端侧算力关，机器人要过毫秒级直觉物理与零样本泛化关，AI 制药则要过长达数月的动物代谢与湿实验资源调度关。

## 关键 Takeaways

### 1. 2026 年 9–10 月行业背景与 Astra 体感分化（详见 [[gpt-6-astra]]）
- **9 月大事记**（主持人口述）：
  - **模型层**：OpenAI 发布 **GPT-6 Astra**，报告未提机器人却空降机器人评测榜首；TypeSafe 推出不生成文本、只给选项打概率的“系统1”决策模型 **Jev**，发布 24 天融资 8.7 亿美元（估值 75 亿美元）。
  - **Agent 层**：**Meta Muse** 给每个用户配一台云端电脑，两周冲上美国 App Store 榜首；竞争对手 **Instinct** 一个月内估值从 25 亿涨至 100 亿美元；xAI 的 **Grok Bot** 开放企业部署。
  - **AI for Science 层**：Claude 仅用 21 小时发现结构类似 CRISPR 的新酶系统 **ART**，引发基因编辑公司股价下跌；扎克伯格夫妇资助的 **Biohub** 联手 DeepMind、Meta、Isomorphic Labs、DOE、NIH 将“虚拟细胞计划”扩大至 **18 亿美元**。
- **三领域实测 Astra 的温差**：
  - **Coding / Agent（朱哲清）**：相比当年 Claude Opus 4.5→4.6“工具调用几乎不再出错、从短程跃升至长程自主编程”的范式转移，Astra 在 Coding 上只是渐进升级（长程上下文更稳、幻觉降低、前端与设计审美提升），跑 24 小时超长任务仍会幻觉，且速度较慢。
  - **机器人（许华哲）**：**定性级的飞跃**。具备把思维链（CoT）反思转化为物理动作调整的能力（撞桌后主动抬高机械臂、多次迭代画金门大桥、捏窄劈叉的花茎再插花），并能凭几张照片快速生成实验室 3D 仿真环境（Real-to-Sim）。
  - **生物医学（王晟）**：**重大节点**，团队已从 Claude 切换至 Astra。两大杀手锏是 **8–24 小时过夜长程任务**与 **Computer Use**（因预训练吸收了大量教程与用户日志，能熟练操作生物医学界数十年前编写、界面极难用的老旧软件如 MultiQC，甚至反向教会跨学科学生如何使用软件）。

### 2. 个人 Agent 商业化困局：Browser Use、IP 封锁与端侧破局（详见 [[zheqing-zhu]]）
- **重回 Browser Use 与 Manus 的老路**：因电商（Amazon）、旅游（Expedia）等第三方平台拒绝开放 API，Meta Muse 与 Instinct 被迫重回浏览器操作（Browser Use）。但云端虚拟机使用的是商用数据中心 IP（哪怕挂 Bright Data 等代理），极易被商家风控屏蔽——**Amazon 已经屏蔽了 Meta Muse**。这也是当年 Manus、Genspark 以及 [[claude-code|Claude Code]] / Cowork、ChatGPT Work 最终纷纷退守“白领办公效率”的核心原因。
- **烧钱获客与沙箱成本**：
  - Meta Muse 为每位用户提供每周 **1 亿免费 Token**（按输入成本折算约 **100 美元/周**）；还要承担昂贵的云端虚拟机 CPU 与内存成本（朱哲清在 RL 大规模 rollout 中发现租虚拟沙箱极贵，CPU 价格甚至一度逼平 GPU，被迫自租大型物理 CPU 主机搭沙箱）。
  - **Astra 定价高昂**：输入 **$10 / 百万 Token**、输出 **$50 / 百万 Token**，是 GPT-6 Sol 的 4–5 倍；跑两三轮复杂 Agent 交互即可烧掉 100 美元额度。若 Meta Muse 将 10% 流量路由给 Astra 或 Fable，单用户月成本将飙至 200 美元。
- **破局关键：身份确认（Identity）与软硬件结合 / 本地小模型**：
  - 商家防的不是真实用户，而是“1 个用户派 20 个云端 Agent 疯狂比价刷乱流量却只贡献 1 份购买力”。若 Agent 运行在用户专属硬件（如 Meta 智能眼镜等可穿戴设备、AI PC、本地 AI Box）并使用家庭宽带 IP，商家能确认 **1:1 真实用户身份代表行为**，才愿意开放访问权限（Access）。
  - 朱哲清（Pokee.ai）押注 **30B 级端侧/私有算力小模型**（与高通、Intel、AMD、联想、惠普合作）：让 60%–70% 的日常广度 Token 与本地浏览器沙箱在私有设备上免费跑通，同时应对全球 RAM/VRAM 昂贵与数据隐私焦虑。
- **前沿 Lab 真正烧 Token 的战场**：不是 C 端聊天，而是 **AI for Science 与未解数学题**。例如 OpenAI 用约 1 万个子 Agent 攻克纳维-斯托克斯（Navier-Stokes）方程，发送 270 万条消息、消耗约 **1300 亿输出 Token**，按零售价折算高达 **2200 万美元**。

### 3. 机器人迎击 Astra：分层下压、快慢系统与“熟肉”数据暗战（详见 [[huazhe-xu]]）
- **控制层边界下压与 TAMP 复兴**：传统架构中 VLM 只管高层任务规划（“拿出西红柿、打鸡蛋”），底层交给具身小模型；Astra 则把能力下压到了低层动作指令（“手往右伸两厘米”“没抓住再往前靠”），使传统略显古板的 **TAMP（任务与运动规划，Task and Motion Planning）** 在 Agentic 时代重获新生。
- **Astra 的四大短板**：
  1. **极慢的推理延迟**（内部加密长 CoT 冗余，简单任务与复杂任务思考时长相近，视频需 16–24 倍速播放，无法做抖毛巾、倒水等高动态任务）；
  2. **缺乏直觉物理（Intuitive Physics）**（难以瞬间预判碰倒水杯会洒、玻璃会碎）；
  3. **空间旋转、插孔与双臂灵巧操作弱**（如叠衣服完全做不了——凡是“语言难以清晰描述”的任务均表现不佳）；
  4. **无肌肉记忆式的熟练度内化**（第 1 次做花 1 小时，第 2 次 45 分钟，第 3 次及以后永远卡在 45 分钟常数，无法像人类或专用小模型那样越练越快直至几秒完成）。
- **产业冲击分化**：
  - **Real-to-Sim 只是视觉 Hype**：虽能快速生成逼真 3D 外观，但并未提升底层物理引擎精度，Sim-to-Real 仍训不出最佳策略。
  - **直接利好硬件本体**：斯坦福团队仅用两周便将 Astra 接入宇树（Unitree）机器人完成家庭任务论文演示；大脑公司将分化为“转做集成部署”与“研发更快更强的端侧具身小模型（理想尺寸 **<10B**，云端准静态任务可容忍 200ms+ 延迟）”。
  - **数据标注升级为“生肉 vs. 熟肉”**：传闻 OpenAI 只买未标注原始数据回内部重标（防泄密且嫌外部标错）。普通采集是“卖生肉/石油”；掌握前沿训练品味、能把**因果关系与直觉物理**（为什么没抓住：位置偏上还是沾水太滑）标清楚的“熟肉数据”单价可翻 **10 倍以上**。
- **Jev 快系统实测与通用机器人时间表**：Jev 因无原生图像输入且缺乏空间平衡反思，在摞方块等机器人任务上表现很差（但可用于快速标数据；传闻 OpenAI 即将发布支持图像多模态的快系统）。许华哲提出**“零样本泛化部署”**愿景（5 个普通工人即可部署，无需 5 个博士驻厂睡 3 个月调夹爪），并给出激进预测：**2028 年初（约 18 个月后），通用机器人将走进家庭，通过语言指令完成家里 90% 的家务。**

### 4. AI 制药的真瓶颈：从干实验满分到湿实验闭环与“Human Use”（详见 [[sheng-wang]]、[[wet-lab-verification-loop]]）
- **知识未涨、安全拒答反噬体验**：Astra 的生物医学提升来自通用 Coding、查文献与长程执行，而非生物医学专有知识；相反，由于前沿模型（Astra、Opus、Fable）生物安全护栏越来越严，动辄 **Refuse to answer（拒绝回答）**，王晟团队日常反而多用 **Kimi K3** 或 **Muse Spark 1.3**，用 Astra 时必须套一层“我只是在设计 Benchmark”的提示词绕过审查。
- **现有生物 Benchmark 的退化**：当前明确定义的生物评测集大多退化成了类似 Kaggle 的数据科学/机器学习工程题（如 Terminal-Bench Science，Astra 虽拿 60 多分但干实验代码能力已超越王晟本人）。真正的药物发现面对的是未知答案，必须靠**湿实验（Wet Lab）**验证。
- **实验设计完成度仅 30% 与“Human Use”**：AI 能生成分子式，但在设计具体湿实验方案（如何合成、何种温湿度储存、小鼠给药周期、如何根据当前实验室仅有的“番茄鸡蛋土豆”器材做菜而非盲目要求“海鲜大餐”）上完成度只有 **30%**，必须依赖资深实验技术员（Technician）修改。王晟将下一代核心能力定义为 **“Human Use / Instruction Generation（人类调度 / 指令生成）”**：从“人写 Prompt 指挥 AI”转向**“AI 根据预算（如 10 万美元）和实验室资源约束，生成清晰无歧义的指令去 Prompt 真实世界的人类技术员或机器人”**，甚至未来仪器不再合成供人眼看的 X 光/CT 图像，而是直接向 AI 输出底层波形信号。
- **制药周期、数据护城河与 MCP 湿实验云**：
  - **临床前时间线与商业闭环**：AI 设计分子只需几小时，但细胞与小鼠实验需数周（期间模型都已迭代到 GPT-6.1/6.2），随后**猕猴（灵长类）实验需 4 个月（做两轮即 8 个月）**。AI 制药初创通常在猴子实验结束（总周期 **6–12 个月**）后直接以 **1000 万美元以上**授权费 License 给拥有患者网络的大药厂做临床人体试验。
  - **单条湿实验数据价值数万至数十万美元**：AlphaFold 1/2/3 与 OpenFold 开源了底层结构预测工具后，真正的护城河转向互联网语料库里绝对没有的真实动物实验数据（“一个分子在小鼠身上能否杀灭癌细胞”这样一条完整数据就值几万至几十万美元）。
  - **前沿实验室自建湿实验室与 MCP 接口**：Anthropic 已自建湿实验团队并与刚融资 **4000 万美元**的云端湿实验公司 **Adaptyv Bio** 深度合作——Anthropic 模型通过 **MCP（Model Context Protocol）** 直接下单做酶/蛋白质设计湿实验验证；酶（工业催化剂，如地沟油转可用油、低温活性洗衣粉）与蛋白质因实验反馈周期短而最先跑通突破，衰老与罕见病则依然漫长。王晟呼吁构建**“无上限（Uncapped）Benchmark”**（如将癌细胞杀伤率从 30% 持续推向 40% 的湿实验数据飞轮）。

### 5. 尾声：普通人还有“被蒸馏”的价值吗？
- **机器人（许华哲）**：在具身领域，**每个普通人都是生活的专家**（做家常菜、叠衣服、走路），在未来 1–2 年内都极具被蒸馏价值，远未到只需蒸馏米其林大厨（Gordon Ramsay）的阶段。
- **科学界（王晟）**：这是**“双向/反向蒸馏”**——跨学科科学家每天都在向 AI 快速学习新领域知识；同时人类牢牢掌握**“定义问题”**（如提出抗衰老活到 200 岁、个体化新病症诉求）与**重大医疗科研决策背书（人类机长）**的不可替代权。
- **模型层（朱哲清）**：当前大模型只是在海量固定场景上做记忆与 **Overfitting（过拟合）**，远未学会“像人一样从零开始高效学习（用一个月交互成为基础医生、三个月成为教授）”；未来真正需要从人类身上蒸馏的不是表层技能，而是**底层的学习方法与直觉（Intuition）**。

## 与 Vault 已有知识的关联

- **[[agent-comfort-zone]] / [[physical-ai-computing]] / [[robot-workflow-loop]]**：本期节目用三个行业的横切面完美印证并扩展了“可验证环境边界”——数学（纳维-斯托克斯）和干实验代码（Terminal-Bench Science）在封闭可验证环境里能靠砸 2200 万美元 Token 快速突破；但一旦跨入机器人实机操作与新药动物代谢，物理引擎失真与生物新陈代谢周期就成了无法靠算力跳过的硬约束（泓君总结：“AI 圈看的是能力曲线，行业人看的是验证与落地周期”）。
- **[[specialized-intelligence]] / [[agi-roadmap-ladder]] / [[complementary-learning-systems]]**：朱哲清指出的“大模型靠过拟合场景而非从零在线学习”、许华哲观察到的“Astra 第 3 次起卡在 45 分钟常数、无法将慢思考内化为几秒钟的肌肉记忆”，从产业实测角度印证了 [[liang-wenfeng|梁文锋]] 与 [[yu-su|苏煜]] 所说的“持续学习 / 小世界模型是当前未过的墙”。
- **[[openclaw]] / [[browser-harness]] / [[sovereign-ai]] / [[memory-wall]]**：朱哲清对 Meta Muse 云端虚拟机被 Amazon 封禁 IP 的剖析、1:1 用户身份验证需求，以及通过 30B 本地模型分流 60%–70% Token 的路线，将 [[openclaw]] 的个人 Agent 浪潮与端侧硬件、内存墙（RAM/VRAM 涨价）及私有算力闭环紧密串联。
- **[[haozhe-wang]] / [[atomic-microscopy]] / [[autogenic-intelligence]]**：王浩哲在硅谷101 Alignment 2026 展示的“AI 科学家连接 CVD 实验设备与显微镜”，与本期王晟提出的“Human Use / MCP 湿实验闭环（Adaptyv Bio）”、“仪器直接向 AI 输出底层波形跳过人类视觉成像”在 AI for Science 范式上高度同构。
