# 梁文锋投资者交流会（完整版全文）

[[deepseek|DeepSeek]] 创始人 **[[liang-wenfeng|梁文锋]]** 在一次融资后的**投资者交流会**上的完整发言 + Q&A（经 X 用户 @falali2015 转录流出，主持人当场提醒勿外传卡量等敏感数字）。这是迄今关于 DeepSeek **愿景、商业哲学、AGI 技术路线、中美算力差距**最系统的一手材料，与 vault 里 [[jensen-huang]]/[[sam-altman]]/[[dario-amodei]] 等美方视角形成强对位。

## 一句话

**「克制是一种战略」**——只赚合理利润（十个月回本≈6 倍利润）、坚持开源、不抢 C 端、不做上游整合，因为「拿得多的人会被拿得少的人打败」；DeepSeek 只做 **AGI 主线**（LM→CoT→Agent→**持续学习**→奇点→具身），C/B 端只是副产品；与美国的差距**只在算力资源**（落后 1–2 年、用 1/20 算力），而 [[cuda|CUDA]] 护城河正被 AI + TileLang + 芯片解耦快速瓦解。

## 关键 takeaways

### 一、愿景与「克制」哲学（[[restraint-as-strategy]]）
- **愿景驱动、无组织**：二十年前最崇拜 Jack Welch 的一句「公司最重要的是愿景」。DeepSeek「没有组织、没有 KPI、没有考核」，愿景甚至不成文——「在做事的方法和对世界的态度里」。「一群平凡的人做出不平凡的事」。
- **克制 = 战略**：「你越克制，越有可能做成。」舍弃换取更大的东西。博弈论内核：**想占 GDP 5% 的会被只要 1% 的打败，再被只要 0.1% 的打败**；愿景拿得多就先输了。
- **只赚合理利润**：API 定价按「买一批设备**十个月回本**」≈ **6 倍利润**；不是利润最大化（价格翻倍需求无弹性、总收入接近翻倍，但他们选择降价，公司群里欢呼）。「十个月回本我们能做到，阿里腾讯成本要高好几倍。」

### 二、开源经济学（更新 [[open-weights-strategy]]）
- **为什么 AI 的开源不冲突商业**：传统软件市场就几十亿、开源即死；但 AI 可能占**人类 GDP 的 10%**，太大、**不可能独占**，不分享就活不下来。
- **部署门槛即护城河**：开源了别人也难做到你的部署成本；**十个月回本的定价让第三方独立部署无利可图**。所以「6 倍利润下开源毫无影响；100 倍利润才会被影响」。
- 开源模型 = 自部署模型（**不留一手**）；去年 C 端全程开源，没看到冲突。

### 三、AGI 技术路线：阶梯（[[agi-roadmap-ladder]]）
- **阶梯**：语言模型 → **CoT**（去年）→ **Agent**（今年）→ **持续学习**（下一个瓶颈）→ **自我迭代的奇点**（渐进非突变、因 AI 加速 AI 而非线性）→ **具身智能**。每一步都建立在前一步上，「没有一步是白走的」。
- **当前 AI**：给它**完整上下文 + 指令**已超过人类，但「给完整上下文」极难。员工类比：新人两个月熟悉环境就能听懂「叫小王来」，AI 缺这两个月的**持续学习**，所以替代不了员工。
- **持续学习是必过的墙**：全世界都还没找到 work 的方法；解决后「通用智能就不在话下」。**「AI 不缺品味和直觉，缺的是持续学习。」**
- **先易后难的路线选择**：先持续学习→奇点→具身，是「最轻松、不用加班」的路径（后面能用前面的技术来开发）；反过来先做具身会很苦。

### 四、中美算力差距（[[china-us-compute-gap]]）
- **差距只在资源**：现约 **2 万张 H 等效**（大部分刚到），激进扩张、基本买英伟达（也买「不合规的卡」）；人才差距本质是算力差距（算力少→实验机会少）。
- **数量级差**：现做 **50B 激活**，下一代 150–250B；美国前沿 **~800B 激活**，训它需 **5 万张 GB300 或 20 万张华为 950**——「哪怕五百亿全花掉也训不起」。
- **叙事**：落后美国 1–2 年、用 **1/20 算力**做出来；目标改写为「用 1/几算力、把时间缩到 3–6 个月，甚至局部超越」。
- **CUDA 护城河快速瓦解**（与 [[jensen-huang]] 正面矛盾）：三因——AI 能写生态 / 自研高级语言 **TileLang** 重写 CUDA 算子 / 计算卡与游戏卡解耦→专用芯片不绑 CUDA。「**英伟达在掘自己的坟墓。**」
- **华为 950 超节点**：性能/任务平替 GB200/GB300（延时一样），代价是「**4 张顶 1 张 + 落后 2 年**」，贵 50–200% 也划算；华为给约 **1.6 万张**（≈4 千张 B 系列），产能是唯一瓶颈。
- **TileLang**：V3 已「**用英伟达卡但不用英伟达生态**」，只需在华为卡上把这套重做一遍；效率不降反升（损失 1–2% 可接受），还在用 AI 写 TileLang。

### 五、组织与商业（更新 [[deepseek]]/[[liang-wenfeng]]）
- **唯一核心利益 = 团队稳定性**：只要人不走就一定能做成 AGI；近期融资的大额期权已很大程度解除此风险。
- **两条管理线**：自下而上（每人自由研究、无 KPI，「摸奖」）+ 自上而下「做正事」（≤员工一半时间）；决策靠**共识**，他的权威建立在共识上。
- **C/B 端是 AGI 的副产品**：站在技术高位做低一级的产品是「降维打击」；去年春节爆火「不在剧本里」。
- **只做 AGI 主线**：不做 3D、视频生成、世界模型（与智能上限无关，虽是好生意）；多模态是「组件」不是主线（V4 后续原生多模态）。
- **一半核心研究员在标数据**：数据≈模型的一半；中国在高端标注上无成本优势，是时间瓶颈。
- **对三大实验室的判断**：Anthropic 在 Code Agent 的先发优势「不长期」、很快没了；OpenAI 与 Google 会交替上升；三家是全球效率最高（烧钱最少）。中国大概率是「**三体之一**」，扮演产量最大 / 最便宜的角色。
