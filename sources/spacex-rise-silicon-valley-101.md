# SpaceX 崛起史：一切，为了去火星

硅谷101实地探访洛杉矶早期厂址与 Starbase，并访谈前高管 Lewis Hong。最值得复用的不是“坚持就能成功”，而是**长期使命如何通过工程删减、商业现金流和高频试验逐步获得支撑**。

## 发展路径

| 时间段 | 叙事重点 | 机制 |
|---|---|---|
| 01:32–12:38 | 从购买火箭受阻到自研；Falcon 1 三次失败后第四次入轨，随后获得 NASA 合同 | 工程进展与融资窗口必须同时成立 |
| 13:05–19:40 | COTS/CRS 与传统成本加成采购模式对照 | 按预定价格和任务结果采购，改变承包商的成本激励 |
| 23:10–29:22 | 零件成本拆解、“白痴指数”、五步工作法 | 先质疑需求和删除，再优化、提速、自动化 |
| 29:46–39:46 | 从 Grasshopper 验证到 Falcon 9 陆地、海上回收 | 分阶段试验、故障分析、周转与复用 |
| 40:18–42:45 | Starlink 订阅收入及自有发射需求 | 发射能力与应用需求相互增强 |
| 45:04–47:50 | Crew Dragon 触屏与紧急按钮设计争论 | 用成本、技术和安全论证修正创始人要求 |
| 51:54–1:03:54 | Starbase 集成制造与发射；Starship 的发动机、材料和快速复用目标 | 优化整套运营系统，不只单个性能指标 |
| 1:09:09–1:14:55 | 社区与环境冲突，及多星球使命 | 工程效率之外仍有公共成本和时间表风险 |

## 三个可复用洞察

1. **使命与商业路径分层**：去火星是方向，NASA 服务合同、发射和通信业务是阶段性经营支撑。宏大使命不能替代客户和现金流。
2. **失败必须产生可定位的学习**：连续试射不是无条件鼓励失败；每轮要识别故障、修改设计并重新验证。太空系统中“多数部件正常”并不代表任务成功。
3. **垂直整合可以创造内部需求循环**：Starlink 不只是发射客户，也提供经常性收入和试验频率。内部订单不会凭空消除成本，需要终端业务形成价值，详见 [[spacex]]。

## 证据边界

- 这是媒体历史叙事与前员工回忆，不等于独立审计。受访者对创始人的评价保留为个人视角。
- 片中 IPO、估值、星链用户与营收、政府合同、复用纪录等带有明确时点，不据此描述 2026-10-22 的现状。
- NASA 合同额在旁白与历史采访片段中存在 16 亿/15 亿美元口径差异；本次不据此制作精确财务时间线。
- Starship 的完全、快速复用及未来发射规模是发展目标，不写成已经实现的常态能力。材料和发动机的性能说明也不升级为通用工程定律。
