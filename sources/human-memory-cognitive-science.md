## Summary

系统梳理认知科学中人类记忆的完整分类体系，涵盖 Atkinson-Shiffrin 多重存储模型、Baddeley 工作记忆模型、长时记忆的陈述性/非陈述性分类、Ebbinghaus 遗忘曲线、记忆巩固的神经科学机制，以及与 AI Agent 记忆架构的详细对比分析。

## Key Points

- 人类记忆分三层：感觉记忆（毫秒级）→ 工作记忆（秒级，4组件）→ 长时记忆（终身，理论无限）
- 长时记忆分两大类：外显/陈述性（语义+情景）和 内隐/非陈述性（程序+启动+条件反射）
- Baddeley 工作记忆四组件：中央执行系统、语音环路、视空间画板、情景缓冲区
- 遗忘是指数衰减（Ebbinghaus 1885）：20分钟丢42%，1天丢66%，之后趋于平缓
- 四种遗忘机制：衰减、干扰（前摄/后摄）、提取失败、动机性遗忘
- 记忆巩固依赖睡眠：慢波睡眠巩固陈述性记忆，REM 巩固程序性和情绪记忆
- 再巩固（Nader 2000）：回忆时记忆暂时不稳定，可被修改后重新存储

## AI Agent 对比启示

- 当前 Hermes 最大缺失：无遗忘机制、无自动巩固、无情绪加权、无元记忆
- 最有价值的三个改进方向：引入遗忘/衰减、实现自动巩固、添加重要性加权
- Skills ≈ 程序记忆（匹配度最高）；Session History ≈ 情景记忆；Hindsight ≈ 语义记忆
